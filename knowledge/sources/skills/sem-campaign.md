# Google Ads SEM 付費搜尋行銷大師

## 角色定義

**核心原則**：此 skill 負責「付費搜尋策略」；有機 SEO 與 GEO 知識來自 `ltc-social-writer` skill，評鑑領域知識來自 `lib/ai/evaluation-profiles/`。絕對不自行編造廣告成效數據，基準值僅供參考，實際數字以帳戶歷史資料為準。

**廣告目標受眾**：
- 主要：長照機構管理者、護理之家院長/主任、日照中心主任
- 次要：社工師、護理師、照服員主管（影響購買決策者）
- 排除：求職者、學生、政策研究者

**廣告文案語氣規範**：
- 使用「您」（正式）
- 專業、急迫、效益導向：先說痛點，再說解法
- 使用政府官方術語（「評鑑」非「考核」、「服務對象」非「病患」、「基準」非「標準」）
- 語言：繁體中文（zh-TW），不使用簡體字或日式漢字
- 遵守 Google Ads 政策：不使用最高級（「最好」、「第一」）、不作無法證明的聲稱

## 轉換追蹤設定

### 目前狀態

`app/layout.tsx` 目前只有 Google AdSense 腳本，**沒有 GA4 或 Google Ads 轉換追蹤**。這是執行 SEM 前最優先要完成的工作。

### 需要的環境變數

在 `.env.local` 新增：
```
NEXT_PUBLIC_GA_MEASUREMENT_ID=G-XXXXXXXXXX     # GA4 評估 ID
NEXT_PUBLIC_GOOGLE_ADS_ID=AW-XXXXXXXXXX        # Google Ads 轉換 ID
```

### 轉換事件定義

| 事件名稱 | 觸發時機 | 優先級 | 對應元件/路徑 |
|---------|---------|--------|------------|
| `sign_up` | 用戶完成帳號註冊 | 主要轉換 | `/auth/sign-up` 完成後 |
| `trial_start` | 匿名試用開始（TrialButton 點擊） | 主要轉換 | `TrialButton` onClick |
| `view_pricing` | 到訪定價頁 | 次要轉換 | `/pricing` page_view |
| `cta_click_start` | 點擊 StartButton | 微轉換 | `StartButton` onClick |
| `cta_click_trial` | 點擊 TrialButton | 微轉換 | `TrialButton` onClick |

### 實作方式

**步驟 1**：建立 `components/analytics.tsx`（client component）
```tsx
'use client'

// GA4 事件追蹤輔助函式
export function trackEvent(eventName: string, params?: Record<string, unknown>) {
  if (typeof window !== 'undefined' && window.gtag) {
    window.gtag('event', eventName, params)
  }
}

// Google Ads 轉換追蹤
export function trackConversion(conversionLabel: string) {
  if (typeof window !== 'undefined' && window.gtag) {
    window.gtag('event', 'conversion', {
      send_to: `${process.env.NEXT_PUBLIC_GOOGLE_ADS_ID}/${conversionLabel}`,
    })
  }
}
```

**步驟 2**：在 `app/layout.tsx` 的 `<head>` 加入 GA4 腳本（使用 `next/script`）

**步驟 3**：在 `StartButton` 和 `TrialButton` 的 onClick 呼叫 `trackEvent`

### 台灣長照 SaaS 預算框架

> 注意：台灣長照機構評鑑關鍵字屬於極小眾 B2B 市場，月搜尋量極低（50–500 次/關鍵字），預算不需過高。

現階段產品免費，無法計算金錢 ROAS。使用以下代理指標衡量廣告效益：

| 指標 | 目標值 | 計算方式 |

| 每次試用啟動成本（CPT） | < NT$150 | 廣告花費 / trial_start 數 |

## A/B 測試框架

### 廣告文案測試協定

1. **一次只測試一個變數**（標題 vs 標題，不同時改描述）
2. **最小樣本量**：每個變體達到 100 次點擊後再比較
3. **統計顯著性門檻**：95% 信賴水準（建議使用線上工具計算）

## 台灣長照市場 SEM 特殊考量

### 極小眾 B2B 市場特性

台灣長照機構總數約數千家（日照約 500+、住宿護理之家約 1,000+），廣告受眾池極小。這意味著：

- **搜尋量極低**：單一關鍵字月搜尋量可能只有 50–200 次，請降低對流量的期待
- **每次點擊價值極高**：小受眾→每個潛在客戶都重要，著陸頁體驗不可妥協
- **再行銷比新客獲取更重要**：受眾有限，讓看過一次的人回來比找新人更有效率
- **廣泛比對必定浪費預算**：台灣長照 B2B 太小眾，廣泛比對會匹配到不相關查詢

### 醫療相關廣告政策注意事項

報告汪是「文書管理工具」，非醫療器材或醫療服務，但廣告中若出現「護理」、「醫院」等詞彙，Google 可能要求完成醫療廣告認證。若廣告審核被拒，可能需要調整訴求方向：
- ✅ 強調「文書管理」、「評鑑備審」
- ⚠️ 謹慎使用「護理紀錄」、「醫療文書」等詞彙
- ✅ 強調「台灣政府評鑑合規」而非「醫療功效」

### 語言精準度要求

使用政府官方評鑑術語，勿自行創造詞彙：

| 正確用語 | 錯誤用語（勿使用）|
|---------|----------------|
| 評鑑 | 考核、稽查、審查 |
| 服務對象 | 病患、用戶、案主 |
| 基準 | 標準、指標 |
| 評鑑委員 | 審委、稽核員 |
| 備審文件 | 申請文件、審查資料 |

### 地理與時程定向

- **地理**：設定台灣（TW），無需細分縣市（長照機構全台分布）
- **語言**：繁體中文（ZH-TW），排除簡體中文
- **時段**：工作日 9:00–18:00 出價調高 20%（機構行政人員工作時間），夜間降低
- **裝置**：行動裝置出價調高 10%（長照工作者常用手機查資訊）
