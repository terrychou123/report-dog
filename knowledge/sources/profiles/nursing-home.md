# 住宿型照顧機構 評鑑基準

> 115年度住宿式長期照顧服務機構績效考核指標（衛生福利部全國版）
> 共 63 項指標 + 加減分 3 項

## A、經營管理效能（管，id 1–9）

### 管1. A1 工作人員權益保障

**負責職務**：負責人/行政主管

**評鑑基準：**
1. 工作人員均依法投保勞工保險、全民健康保險及提繳勞工退休金
2. 訂有工作人員申訴管道並公告，且有申訴紀錄及處理情形
3. 工作人員薪資符合基本工資規定，且按時發放
4. 訂有工作人員工作規則並依法報主管機關核備
5. 提供工作人員合理工作環境，無違反勞動基準法情事

### 管2. A2 服務對象入出機構作業

**負責職務**：社工/護理師

**評鑑基準：**
1. 訂有入住審核作業規範，入住前完成健康評估及相關資料收集
2. 入住時提供服務對象及家屬機構介紹，並辦理入住手續
3. 訂有出院（所）作業程序，包含轉介、返家、死亡等情形
4. 死亡服務對象依規定辦理通報，且有後續家屬聯繫紀錄
5. 出院（所）後有追蹤訪視紀錄（適用返家或轉介者）

### 管3. A3 業務計畫訂定與執行

**負責職務**：負責人/行政主管

**評鑑基準：**
1. 每年訂有業務工作計畫，內容涵蓋各項服務業務目標
2. 業務計畫依時程執行，並有定期進度追蹤紀錄
3. 年度結束後完成業務計畫執行成果檢討報告
4. 業務計畫訂定過程有跨部門參與及主管審核簽核

### 管4. A4 前次評鑑（查核）缺失改善情形

**負責職務**：負責人/品管

**評鑑基準：**
1. 前次評鑑（查核）缺失項目均有列冊追蹤
2. 各缺失項目訂有改善計畫，包含改善措施、負責人員及完成期限
3. 缺失改善完成後有書面紀錄及主管確認簽核
4. 持續監測改善成效，防止缺失事項再度發生

### 管5. A5 機構內性騷擾及性侵害事件防治機制

**負責職務**：負責人/社工

**評鑑基準：**
1. 訂有性騷擾防治政策及申訴處理程序，並公告周知
2. 設有性騷擾申訴窗口，且處理流程符合性別平等工作法規定
3. 工作人員接受性騷擾防治及性別平等相關教育訓練
4. 服務對象發生性騷擾或性侵害事件，依規定辦理通報及後續處理

### 管6. A6 危機事件及緊急應變處理機制

**負責職務**：負責人/護理師

**評鑑基準：**
1. 訂有危機事件應變計畫
2. 危機事件發生後依規定時限辦理通報，且有紀錄
3. 訂有緊急聯絡名單，並定期更新
4. 定期演練危機應變程序，工作人員熟知各自職責

### 管7. A7 業務負責人資格及執業情形

**負責職務**：負責人

**評鑑基準：**
1. 業務負責人符合長期照顧服務機構設立許可及管理辦法規定資格
2. 業務負責人實際管理機構業務，有參與服務品質相關會議之紀錄
3. 業務負責人每月至少一次至機構查看實際照護情形，並有書面紀錄
4. 業務負責人依規定完成在職教育訓練

### 管8. A8 聘用工作人員（含專任、兼任）設置情形

**負責職務**：負責人/行政主管

**評鑑基準：**（合併原A8社工/A9護理/A10兼任/A11照服）
1. 社會工作人員依法設置，具備社會工作師證書或符合資格條件，且執業登錄與服務機構相符
2. 護理人員依法設置，持有效執照執業；日班護病比≤9，夜班護病比≤15
3. 兼任醫師、物理治療師、職能治療師、營養師等專業人員依規定聘用並有服務紀錄
4. 照顧服務員依規定設置比例，持有照顧服務員訓練結業證明書或相關資格
5. 廚工及其他工作人員符合業務需求，並依法辦理相關健康檢查

### 管9. A9 工作人員教育訓練計畫訂定及辦理情形

**負責職務**：負責人/護理主管

**評鑑基準：**（合併原A13新進/A14在職/A15廚工）
1. 訂有年度工作人員教育訓練計畫，涵蓋職前訓練及在職訓練
2. 新進工作人員完成職前訓練並有紀錄
3. 護理人員在職訓練每年至少16小時，照顧服務員每年至少20小時，並有完整紀錄
4. 廚工完成食品安全衛生及從業人員健康管理相關訓練
5. 教育訓練辦理情形有統計及分析，作為次年度計畫改善依據

## B、專業照護品質（專，id 10–38）

### 專10. B1 服務品質改善會議及檢討機制（id:10）

**負責職務**：負責人/護理主管

**評鑑基準：**
1. 定期（至少每季）召開服務品質改善會議，並有會議紀錄
2. 會議中提出服務品質指標數據，進行分析與檢討
3. 會議決議事項有追蹤管考機制及改善成效記錄
4. 各專業人員（護理、社工、復健、營養）均參與品質改善會議

### 專11. B2 個案服務計畫評值（含社工及護理共同評值）（id:11）

**負責職務**：社工/護理師

**評鑑基準：**
1. 新收個案於入住14日內完成個別化服務計畫，由社工及護理人員共同評估
2. 個案服務計畫涵蓋生理、心理、社會、靈性等全人照護需求
3. 服務計畫至少每6個月評值一次，或依個案狀況變化隨時修訂
4. 個案服務計畫評值有個案（或家屬）參與，並有簽名或同意紀錄
5. 抽查服務計畫與實際照護措施之符合程度

### 專12. B3 新入住服務對象適應輔導（id:12）
**評鑑基準：** 入住適應輔導紀錄完整；針對適應困難個案有個別化輔導措施；追蹤適應情形。

### 專13. B4 跨專業整合照護服務（id:13）
**評鑑基準：** 定期召開跨專業照護計畫討論會議（含護理、社工、復健、營養等）；跨專業整合照護記錄完整；有轉介照會機制及記錄。

### 專14. B5 辦理團體活動及社區參與（id:14）
**評鑑基準：** 定期辦理團體休閒活動；辦理社區參與活動；服務對象參與活動有紀錄。

### 專15. B6 結合社區資源提供服務（id:15）
**評鑑基準：** 建立社區資源清單並定期更新；依個案需求引介社區資源；與社區志工或宗教團體有合作關係。

### 專16. B7 促進服務對象與家屬互動（id:16）
**評鑑基準：** 辦理家屬聯繫活動；主動通知家屬服務對象健康或服務計畫異動；協助家屬參與照護計畫討論。

### 專17. B8 例行醫療照護及就醫安排（id:17）
**評鑑基準：** 服務對象定期接受醫師診視；慢性病用藥管理完整；安排牙科眼科等定期外診；護理人員依醫囑執行護理處置有完整記錄。

### 專18. B9 傳染病防治及感染管制（id:18）

**負責職務**：感控負責人/護理師

**評鑑基準：**
1. 訂有感染管制計畫，包含標準預防措施、傳染病通報及隔離措施
2. 工作人員落實手部衛生，有稽核紀錄
3. 訂有傳染病疫情監測機制，並有通報及後續處理紀錄
4. 工作人員接受感染管制教育訓練，每年至少6小時
5. 備有充足個人防護裝備，並有管理機制

### 專19. B10 處方藥品管理（id:19）

**評鑑基準：**
1. 藥品依規定儲存，冷藏藥品有溫度監控紀錄
2. 藥品有明確標示（服務對象姓名、藥品名稱、劑量及用法）
3. 給藥前確實執行三讀五對，有給藥紀錄
4. 管制藥品依法管理，有領取、使用及銷毀紀錄
5. 藥品有效期限定期檢查，過期藥品依規定處理

### 專20. B11 藥事照護服務（id:20）
**評鑑基準：** 定期辦理藥師藥事照護服務；定期檢視多重用藥及潛在不適當用藥；有藥物不良反應通報機制。

### 專21. B12 跌倒預防及處理（id:21）

**評鑑基準：**
1. 入住時完成跌倒風險評估，高風險個案訂有預防措施
2. 每季至少重新評估跌倒風險
3. 跌倒事件發生後24小時內完成通報，並有事件分析及改善措施
4. 環境安全巡查定期辦理
5. 跌倒發生率有統計並定期分析，列為品質監測指標

### 專22. B13 壓力性損傷預防及處理（id:22）

**評鑑基準：**
1. 入住時完成壓力性損傷風險評估（如Braden量表）
2. 定期（至少每週）評估皮膚狀況
3. 壓力性損傷發生後依傷口分期訂定照護計畫
4. 高風險個案執行定時翻身或使用減壓設備，有執行紀錄
5. 壓力性損傷發生率有統計並定期分析

### 專23. B14 疼痛評估及處理（id:23）
**評鑑基準：** 定期執行疼痛評估（標準化工具）；有疼痛之個案訂定疼痛管理計畫；處理介入後追蹤評估效果。

### 專24. B15 身體約束使用管理（id:24）

**評鑑基準：**
1. 訂有身體約束政策，以最小使用原則，需有醫師評估及家屬（或服務對象）同意
2. 使用約束前評估替代措施，並有記錄
3. 約束使用中定期（至少每2小時）評估約束必要性及服務對象狀況
4. 約束解除後重新評估，持續追蹤
5. 身體約束使用率有統計，並定期檢討降低約束措施

### 專25. B16 感染事件預防及處理（id:25）
**評鑑基準：** 定期監測常見感染事件；感染事件發生後有個案處理紀錄；群聚感染事件依規定通報。

### 專26. B17 非計畫性住院管理（id:26）
**評鑑基準：** 非計畫性住院事件有紀錄；發生後進行原因分析訂有改善措施；非計畫性住院率有統計，列為品質監測指標。

### 專27. B18 非計畫性體重變化管理（id:27）
**評鑑基準：** 每月測量服務對象體重；非計畫性體重減輕（1個月超過5%或3個月超過7.5%）有追蹤及介入措施；非計畫性體重變化率有統計。

### 專28. B19 管路移除（鼻胃管及導尿管）（id:28）

**負責職務**：護理師

**評鑑基準：**（合併原B20鼻胃管移除及B21導尿管移除）
1. 訂有鼻胃管及導尿管使用評估及移除作業規範
2. 定期評估管路必要性，具體推動管路移除計畫
3. 管路移除成功個案有追蹤記錄（移除後進食或排尿功能評估）
4. 留置管路個案定期重新評估移除可行性，紀錄完整
5. 管路移除率有統計，並定期分析

### 專29. B20 服務對象健康檢查（id:29）
**評鑑基準：** 服務對象每年至少辦理一次健康檢查；健康檢查結果有追蹤及後續醫療處置記錄；依結果調整個案照護計畫。

### 專30. B21 侵入性照護技術管理（id:30）
**評鑑基準：** 侵入性照護依標準程序執行；定期辦理侵入性照護技術訓練及考核；侵入性照護相關感染事件有監測及改善機制。

### 專31. B22 緊急送醫作業（id:31）
**評鑑基準：** 訂有緊急送醫作業程序；緊急送醫時依規定通知家屬；轉介紀錄需包含診斷、治療及後續返院照護銜接。

### 專32. B23 疫苗注射服務（id:32）
**評鑑基準：** 每年辦理流感疫苗接種；依衛生主管機關規定辦理其他疫苗接種；服務對象及工作人員疫苗接種率有統計。

### 專33. B24 促進日常活動及下床（id:33）
**評鑑基準：** 依服務對象功能狀況訂定活動促進計畫；每日記錄服務對象下床及活動情形；長期臥床個案有預防廢用症候群計畫。

### 專34. B25 身體清潔及翻身照護（id:34）
**評鑑基準：** 服務對象依需求提供沐浴或擦澡；臥床個案每2小時翻身一次；口腔清潔每日至少2次；個人清潔照護尊重隱私。

### 專35. B26 失禁服務對象定時如廁計畫（id:35）【115年度新增】

**負責職務**：護理師/照服員

**評鑑基準：**
1. 失禁服務對象完成排泄功能評估，訂有個別化定時如廁計畫
2. 定時如廁計畫依服務對象排泄型態執行，有執行紀錄
3. 定期評估定時如廁計畫成效，並依評估結果調整頻率或方式
4. 工作人員接受失禁照護及定時如廁計畫相關訓練

### 專36. B27 自我照顧能力維持及輔具使用（id:36）
**評鑑基準：** 定期評估服務對象自我照顧能力（ADL量表）；依評估結果訂定訓練或維持計畫；輔具使用依需求評估，有輔具清單及維護記錄。

### 專37. B28 膳食及個別化飲食照護（id:37）

**負責職務**：營養師/廚工

**評鑑基準：**（合併原B29膳食菜單/B30個別化飲食/B31適宜餐具）
1. 依服務對象飲食需求提供個別化餐食
2. 菜單每季至少更換一次，由營養師審核，符合衛生福利部膳食營養素建議量
3. 使用適宜餐具（如加厚握柄、防滑碗盤），協助飲食困難服務對象進食
4. 烹調及備餐場所符合食品衛生安全規定，定期進行環境衛生稽查
5. 服務對象飲食照護有紀錄，包含進食量評估及異常狀況處理

### 專38. B29 管灌飲食照護（id:38）
**評鑑基準：** 管灌服務對象有完整的管灌飲食計畫（配方種類、量及頻率）；管灌前確認管路位置；定期評估管灌個案的營養狀態及管灌耐受性。

## C、安全環境設備（安，id 39–54）

### 安39. C1 建築物安全維護（id:39）
**評鑑基準：** 建築物定期安全維護檢查及公共安全申報有紀錄；設施設備定期保養維護，異常狀況即時修繕；無障礙設施設置完整。

### 安40. C2 寢室及生活空間環境管理（id:40）
**評鑑基準：** 寢室空間符合法規規定；寢室環境保持整潔，溫度、通風適當；服務對象個人隱私受保障（如床簾）；生活輔助設施（扶手、防滑墊、呼叫系統）功能正常。

### 安41. C3 浴廁及盥洗設備安全（id:41）
**評鑑基準：** 浴廁設施符合服務對象使用需求，有防滑設施及緊急呼叫系統；浴廁溫度控制設備功能正常（防燙傷）；浴廁定期清潔消毒有紀錄。

### 安42. C4 餐廳及廚房衛生管理（id:42）
**評鑑基準：** 廚房符合食品衛生安全規範，有定期衛生稽查紀錄；食材採購、驗收、儲存各環節均有管理程序；廚工持有效健康檢查證明。

### 安43. C5 污物及廢棄物處理（id:43）
**評鑑基準：** 感染性廢棄物依規定分類處理；污物處理流程符合感染管制規範；廢棄物暫存場所清潔，定期清運有紀錄。

### 安44. C6 藥品及醫療器材安全管理（id:44）
**評鑑基準：** 藥品儲存符合規定（溫度、光線、濕度控制）；醫療器材定期校正及維護；急救設備（AED、急救箱）定期檢查確保功能正常。

### 安45. C7 電梯及機械升降設備安全（id:45）
**評鑑基準：** 電梯依規定辦理定期安全檢查，有合格紀錄；出現異常立即停用並通報維修。

### 安46. C8 緊急發電及停電應變（id:46）
**評鑑基準：** 設有緊急發電設備，定期試運轉並有紀錄；停電應變計畫完整，工作人員熟知停電處理程序。

### 安47. C9 用電安全及消防管理（id:47）

**負責職務**：負責人/防火管理人

**重要更新（115年度新增要求）：**
1. 用電安全管理：每月自主安全檢查、半年委外電氣設備安全檢驗，有紀錄
2. 設有電氣設備清單，定期以熱顯像儀或其他方式辦理用電設備檢查
3. **防火管理人不得由社工、醫事人員或照顧服務員兼任**（須由管理或監督層次人員擔任）
4. 消防安全設備（灑水系統、滅火器、警報系統等）定期維護保養，有紀錄
5. 消防安全設備定期委由消防設備師（士）檢修，有報告書

### 安48. C10 等待救援空間設置（id:48）

**重要更新（115年度明確三項要求）：**
1. 設有等待救援空間（防火區劃），**空間構造採不燃材料，設有防火門（甲種）**
2. 等待救援空間**具備防排煙功能**（機械排煙或自然排煙），消防搶救可及性良好
3. 等待救援空間有明確標示，定期辦理功能測試

### 安49. C11 緊急應變（EOP）演練（id:49）

**重要更新（115年度新增：4次→含桌上模擬）：**
1. **每年辦理緊急應變演練至少4次**（含複合式演練1次及夜間演練1次；另2次可採桌上模擬演練）
2. 緊急應變演練計畫事前訂定，演練後有檢討及改善紀錄
3. 演練涵蓋火災、地震、颱風等不同情境

### 安50. C12 疏散策略及持續照護作業程序（id:50）

**重要更新（115年度擴大訓練對象）：**
1. 依服務對象失能程度訂有個別化疏散策略
2. **疏散訓練對象涵蓋所有工作人員，包含替代役男及家屬自聘看護工**
3. 訂有疏散後持續照護作業程序（含醫療、用藥、飲食、輔具等需求）
4. 工作人員接受疏散策略教育訓練並有紀錄；實地抽測工作人員執行疏散之能力

### 安51. C13 情境式火災風險辨識與疏散演練（id:51）
**評鑑基準：** 依不同起火位置訂有情境式疏散計畫；工作人員能正確辨識火災風險及執行對應疏散措施，實地抽測；情境演練評估紀錄完整。

### 安52. C14 疏散避難通道及設施維護（id:52）
**評鑑基準：** 疏散避難通道保持暢通，無障礙物堆積；疏散指示標誌清晰可見，緊急照明設備功能正常；防火門保持正常關閉狀態。

### 安53. C15 物理環境安全及無障礙設施（id:53）
**評鑑基準：** 機構內無障礙設施符合身心障礙者使用需求；地板防滑處理完善；照明充足，走廊、樓梯、浴廁等區域照度符合安全需求。

### 安54. C16 輔具與移位設備安全管理（id:54）
**評鑑基準：** 移位設備定期維護保養；工作人員接受正確移位技術訓練；輔具借用有管理紀錄，定期辦理安全功能檢查。

## D、個案權益保障（權，id 55–63）

### 權55. D1 服務對象人身安全及尊嚴維護（id:55）
**評鑑基準：** 訂有服務對象人身安全及尊嚴保障政策；有申訴及通報機制；不當對待事件依規定通報；工作人員接受尊嚴維護相關教育訓練。

### 權56. D2 入住契約及服務說明（id:56）

**重要更新（115年度新增）：**
1. 入住前提供服務對象及家屬審閱契約，**審閱期至少5天**
2. **公費安置或緊急安置個案依規定辦理，無須簽訂契約之情形依法處理**
3. 契約內容符合長期照顧服務機構服務契約範本規定
4. 收費依公告標準，無超收費用情事，收費明細透明
5. 服務對象及家屬對服務內容有知情同意之紀錄

### 權57. D3 服務對象隱私及個人資料保護（id:57）
**評鑑基準：** 訂有服務對象個人資料保護政策，依個人資料保護法規定辦理；服務對象相關資料之蒐集、處理及利用有取得同意；個案紀錄妥善保管，防止未授權人員取閱。

### 權58. D4 服務對象申訴及意見處理機制（id:58）
**評鑑基準：** 訂有申訴處理程序，申訴管道公告周知；申訴事件有紀錄，處理期限及結果均有書面回覆；定期辦理服務對象及家屬滿意度調查並有改善措施。

### 權59. D5 服務對象自主選擇及參與決策（id:59）
**評鑑基準：** 尊重服務對象在日常生活之自主選擇；服務對象參與個人照護計畫之討論與決定；具認知障礙之服務對象仍依其能力維持最大程度之自主。

### 權60. D6 服務對象居家情境及監視設備管理（id:60）

**重要更新（115年度明確規範）：**
1. 服務對象居室具居家情境，提供個人化生活空間
2. 機構內監視設備（如有）之設置有合理說明，並告知服務對象及家屬
3. **在必要安全範圍內可設置熱影像偵測設備，惟需取得服務對象或家屬同意**
4. 監視或偵測設備不得侵害服務對象隱私（浴廁、更衣室禁止設置）

### 權61. D7 服務對象財物及遺物管理（id:61）

**重要更新（115年度新增）：**
1. 服務對象財物（現金、貴重物品）有清冊並妥善保管，有取用紀錄
2. 服務對象死亡後遺物有清點清冊，依規定聯絡家屬辦理
3. **無家屬或家屬失聯之服務對象，機構協助建立家屬關係並辦理遺物管理，有完整紀錄**

### 權62. D8 安寧緩和醫療及病人自主權利（id:62）

**重要更新（115年度新增病主法要求）：**
1. 提供服務對象及家屬安寧緩和醫療相關資訊與諮詢
2. **依病人自主權利法（病主法）協助服務對象辦理預立醫療決定（AD）諮商及相關程序**
3. 協助服務對象辦理安寧緩和意願書，並存入個案紀錄
4. 工作人員接受安寧緩和醫療及病主法相關教育訓練
5. 建立安寧緩和醫療轉介機制，與醫療機構有合作關係

### 權63. D9 服務對象宗教信仰及文化需求（id:63）
**評鑑基準：** 尊重服務對象之宗教信仰，提供必要之宗教活動空間或協助；依服務對象文化背景提供適切之飲食、節慶活動及生活照護。

## 加減分項目（創，id 64–66）

### 創64. 加分① 創新或配合政策執行（id:64）

**評鑑基準：**（最多 +2 分）
- 推動創新服務模式或配合政府長照政策執行（如長服法§46相關規定），有具體成效
- 參與衛生福利部或地方政府辦理之長照相關計畫或試辦方案
- 創新服務或政策執行成果有書面紀錄及成效評估

### 創65. 加分② 機構內空氣品質管理（id:65）【115年度新增】

**評鑑基準：**（最多 +1 分）
- 機構公共空間（客廳、餐廳、走廊）定期監測室內空氣品質，**CO₂濃度維持在1000ppm以下**
- 有室內空氣品質監測紀錄（含監測日期、地點及數值）
- 空氣品質不符標準時，有通風改善措施及後續追蹤紀錄

### 創66. 扣分③ 評鑑期間之違規及重大負面事件（id:66）

**評鑑基準：**（最多 -2 分）
- 評鑑期間無發生未依規定通報之重大意外或緊急事件
- 評鑑期間無發生違法情事（如超收費用、違規廣告等）
- 評鑑期間無住民人身安全侵害或重大人權侵犯事件
- 配合評鑑作業，提供正確完整資料，無蓄意隱匿或提供不實資料情事
