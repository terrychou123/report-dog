# 住宿型照顧機構 評鑑基準

> 114年度臺北市老人安養暨長期照顧機構評鑑指標

## A、經營管理效能（管）

### 管1. A1. 工作人員權益相關制度訂定及執行情形

- **負責職務**：行政
- **審查方式**：文件檢閱、現場訪談；檢視工作手冊及權益制度；訪談工作人員；確認勞健保依實際薪資投保


**評鑑基準：**

1. 訂定工作手冊，內容應明列機構組織架構、各單位及人員業務執掌、重要工作流程、緊急事件求助與通報等聯繫窗口、電話等資料，以及辦理住民及家屬防火衛教措施、針對吸菸及情緒不穩住民之防範措施、危險物品管理措施及定期查驗
2. 訂定工作人員權益相關制度，包括：差假制度、教育訓練、薪資給付制度、退休撫恤制度、申訴制度、考核獎勵制度、勞健保之辦理及身心健康維護措施等
3. 確實依據制度執行，並有佐證資料
4. 至少每年1次修訂或審視工作手冊及相關制度

### 管2. A2. 入出機構之管理（二級加強）

- **負責職務**：行政
- **審查方式**：文件檢閱、現場訪談；檢閱入住流程；核查現場人數與類型；向主管機關查詢近4年違規記錄


**評鑑基準：**

1. 收容個案類型符合主管機關許可立案時收案類型
2. 機構收容人數符合主管機關許可立案床數
3. 訂有服務對象入出機構辦法，內容至少包含服務對象、流程與評估機制、服務計畫及收費標準等，並有定期修訂
4. 有專人辦理服務對象入出機構之業務，並確實依據辦法執行
5. 最近4年無違規收容紀錄

### 管3. A3. 業務計畫及營運（或政策）方針之擬訂與執行情形

- **負責職務**：行政
- **審查方式**：文件檢閱、現場訪談；檢視業務計畫及短中長程發展計畫內容及執行情形；與主任（院長）訪談


**評鑑基準：**

1. 應訂定年度業務計畫
2. 各項業務依計畫確實執行，並應有紀錄及具體績效
3. 應訂定短、中長程（3年以上）工作營運發展計畫，並具可行性
4. 年度業務計畫應於前1年度訂定

### 管4. A4. 過去4年接受目的事業主管機關查核缺失改善情形

- **負責職務**：行政
- **審查方式**：與主管機關確認機構過去4年接受查核改善情形


**評鑑基準：**

1. 過去4年接受目的事業主管機關查核缺失改善情形（包含衛福、消防、建管、勞工等主管機關）
2. 改善情形達100%（過去4年查核無缺失者，本項以A計分）

### 管5. A5. 機構內住民保護、性侵害及性騷擾事件防治機制建置情形

- **負責職務**：行政
- **審查方式**：文件檢閱、現場訪談；檢視相關辦法及流程；現場分別與主任（院長）及工作人員會談；如聘有外勞應有適用該國語言之版本


**評鑑基準：**

1. 訂有住民保護、性騷擾及性侵害事件處理辦法及流程（含通報流程、轉介），若有發生相關事件均有處理過程紀錄
2. 分別訂住民保護、性騷擾及性侵害預防措施，並確實執行；若有發生的事件能分析檢討，並有改善方案及執行情形
3. 工作人員清楚處理流程（含申訴及再申訴流程）

### 管6. A6. 危機或緊急事件風險管理情形

- **負責職務**：行政
- **審查方式**：文件檢閱、現場訪談；檢閱風險管理計畫；查核紀錄完整性；訪談工作人員事件處理方式；確認半年定期分析執行情形


**評鑑基準：**

1. 訂有機構危機或緊急事件風險管理計畫，選擇3個（含）以上的風險及危機訂定計畫（如策略風險、營運風險、財務風險、天然災害、意外事件、環境設施設備安全事故等）
2. 有明確具體處理程序、措施
3. 事件發生時，能依計畫確實執行並有處理過程之紀錄
4. 每半年定期對發生之事件檢討，有分析報告、檢討改善措施及追蹤紀錄

### 管7. A7. 業務負責人實際參與行政作業與照顧品質管理情形（一級必要）

- **負責職務**：行政
- **審查方式**：文件檢閱、現場訪談；確認業務負責人（主任/院長）資格；檢視勞健保及勞退金投保明細；現場訪談


**評鑑基準：**

1. 資格符合相關法規規定
2. 專任且於機構投保勞健保、提撥勞退金
3. 實際參與行政與照護品質管理

### 管8. A8. 社會工作人員設置情形

- **負責職務**：行政
- **審查方式**：文件檢閱、現場訪談；檢核工作人員名冊及資格；核對服務簽到紀錄及個案紀錄；檢視4年內配置狀況


**評鑑基準：**

1. 聘任人數及人員資格符合相關法規標準規定（長照型/養護型/失智型 1:100；安養 1:80）
2. 兼任人員之資格及服務人數符合規定；兼任社工應向原任職單位報備且有同意證明並投保勞保

### 管9. A9. 護理人員設置情形（一級必要）

- **負責職務**：行政
- **審查方式**：文件檢閱、現場訪談；檢視工作人員名冊及證明；核對排班表、護理紀錄及照護紀錄；確認4年內配置狀況


**評鑑基準：**

1. 聘任人數符合機構設置標準規定（長照型1:15；養護型1:20；失智型1:20）
2. 護理人員完成執業登錄
3. 全日均應有護理人員上班
4. 最近4年內護理人員之聘用無違規紀錄

### 管10. A10. 兼任（特約）專業人員設置情形

- **負責職務**：行政
- **審查方式**：文件檢閱、現場訪談；檢視工作人員名冊及各類專業人員相關證明；核對排班表及服務簽到紀錄


**評鑑基準：**

1. 有合格且符合機構設置標準之專業人員（含營養師、物理治療師（生）、職能治療師（生）、醫師等）
2. 兼任（特約）之專業人員依法完成支援報備程序，具主管機關核定支援報備之公文或合約，並有到勤紀錄

### 管11. A11. 照顧服務員設置情形（一級必要）

- **負責職務**：行政、護B
- **審查方式**：文件檢閱、現場訪談；檢視工作人員名冊及相關證明；核對排班表及照護紀錄；現場瞭解實務操作；檢視4年內配置狀況


**評鑑基準：**

1. 所聘照顧服務員人數及人員資格符合法規規定（長照型日1:5/夜1:15；養護型日1:8/夜1:25；失智型日1:3/夜1:15；安養型日1:15/夜1:35），外籍照服員人數不超過本國籍照服員及護理人員總人數
2. 全日各班應有我國籍照服員上班
3. 每位照顧服務員確實執行照顧服務工作，並熟悉照顧之實務操作

### 管12. A12. 工作人員勞動條件符合法令情形

- **負責職務**：行政
- **審查方式**：文件檢閱、現場訪談；與工作人員訪談；詢問主管機關；由主管機關配合提供資料


**評鑑基準：**

1. 近4年內無違反勞動基準法經處罰之情事
2. 近4年內無違反性別工作平等法經處罰之情事
3. 近4年內無違反勞工退休金條例經處罰之情事

### 管13. A13. 新進工作人員職前訓練情形

- **負責職務**：行政
- **審查方式**：文件檢閱；檢閱職前訓練項目、內容及紀錄（相關訓練證明以正本呈現）；檢閱新進人員適任性考核資料


**評鑑基準：**

1. 新進工作人員至少接受16小時職前訓練，訓練內容應包括：整體環境介紹、防災概論、勞工安全衛生教育至少3小時、感染管制至少4小時、緊急事件處理、實地操作及老人保護概念等
2. 新進工作人員之職前訓練，應於到職後1個月內完成
3. 對於訓練有效益評量，包含機構適任性考核與受訓人員意見調查或回饋表

### 管14. A14. 在職教育訓練計畫訂定及辦理情形

- **負責職務**：行政
- **審查方式**：文件檢閱；檢閱在職教育訓練項目、內容及紀錄（相關訓練證明以正本呈現）


**評鑑基準：**

1. 訂定員工在職教育訓練計畫，訓練內容必須包括：專業服務、服務對象安全、服務對象權益、急救、意外傷害、性別議題、性侵害和性騷擾防治、感染管制及危機管理、緊急事件處理等議題
2. 每位工作人員每年至少接受20小時，其中感染管制至少4小時
3. 每年每位護理人員及照顧服務員，具有接受急救相關訓練有效期之完訓文件證明
4. 定期辦理勞工安全相關在職訓練
5. 機構內辦理教育訓練應有評值
6. 訂有工作人員參與機構外各類教育訓練辦法
7. 參與各類機構外教育訓練之人員應有心得報告

### 管15. A15. 廚工及供膳人員領照及接受教育訓練情形

- **負責職務**：行政
- **審查方式**：文件檢閱；檢閱廚工是否具有丙級以上餐飲技術士執照；檢閱每年接受營養及衛生相關教育訓練紀錄


**評鑑基準：**

1. 負責膳食廚工應有丙級以上餐飲技術士執照
2. 每年至少接受8小時營養及衛生之教育訓練（係指接受外部訓練，如餐飲工會等）

## B、專業照護品質（專）

### 專16. B1. 定期召開服務品質會議及其辦理情形

- **負責職務**：行政
- **審查方式**：文件檢閱、現場訪談；與工作人員會談；檢視會議紀錄是否確實依決議事項執行及追蹤


**評鑑基準：**

1. 每3個月定期召開機構內部服務品質相關會議，應包含服務品質及工作改善等內容，並針對提升服務品質內容做議題討論
2. 會議決議事項須有執行及追蹤管考制度

### 專17. B2. 個案服務計畫與評值及管理情形（二級加強）

- **負責職務**：社工、護理
- **審查方式**：文件檢閱、現場訪談；抽閱至少5位服務對象個案服務計畫；請教各類專業人員評估與計畫擬定方式；檢閱體重測量紀錄


**評鑑基準：**

1. 新進服務對象應於入住72小時內完成個別化服務，包括身體、心理、社會及高風險評估等（高風險評估至少包含跌倒、壓力性損傷、營養不良三項）
2. 至少每3個月（安養機構6個月）或依服務對象需要評估身體（含營養）、心理、社會、認知及活動功能
3. 執行服務措施與照顧計畫一致，並每半年至少1次依評估結果與服務對象或家屬共同討論修正照顧計畫
4. 建立每位服務對象的資料檔，並依規定年限妥善保存；依相關法規制定個案資料調閱辦法，並有相關調閱紀錄

### 專18. B3. 機構資訊化建置及管理情形

- **負責職務**：社工
- **審查方式**：文件檢閱、實地察看；檢閱資訊使用管理規範及安全管理規範；請工作人員實際操作電腦確認密碼系統及權限


**評鑑基準：**

1. 有服務單位網頁介紹服務內容（含收費標準）
2. 訂有資訊管理規範（含安全管理機制）
3. 有服務對象管理系統，並隨時更新內容
4. 有專人維護

### 專19. B4. 服務對象適應輔導或支持措施

- **負責職務**：社工
- **審查方式**：文件檢閱、現場訪談


**評鑑基準：**

1. 訂有服務對象適應輔導或支持措施（含環境、人員、權利及義務等之解說）
2. 對出現適應不良或情緒不穩之服務對象有輔導關懷及處理，若出現嚴重情況有社工、醫護或其他相關專業人員協處，上開情形皆有完整紀錄
3. 能確實回應服務對象之需求，並留有紀錄

### 專20. B5. 跨專業整合照護執行情形

- **負責職務**：社工
- **審查方式**：文件檢閱、現場訪談；抽閱至少5位服務對象之個案服務紀錄；請教工作人員轉介照會作法


**評鑑基準：**

1. 訂有轉介或照會之條件、流程、表單等機制
2. 每3個月召開專業聯繫會或個案討論會（至少3種不同領域人員參與），並有紀錄及追蹤
3. 依個案需求，確實轉介或照會醫療團隊或其他專業，且有紀錄及追蹤
4. 檢視專業人員之建議，是否落實於照顧服務中

### 專21. B6. 服務對象團體或社區活動辦理情形

- **負責職務**：社工
- **審查方式**：文件檢閱、現場訪談；檢視社交、活動辦理紀錄；請教服務對象參與活動情形；檢視參與成員個別評估紀錄


**評鑑基準：**

1. 訂有符合服務對象需求之各類文康活動或團體工作年度計畫，內容多元，涵蓋動態及靜態活動，並有鼓勵服務對象參與之策略
2. 有專人負責或規劃服務對象的個別、團體、社區活動
3. 每月至少辦理1次團體或社區活動（可配合節慶），並有紀錄（含活動辦理時間、參加成員、活動內容、活動過程、量與質之評值成果、活動照片等），且應評值活動對服務對象的助益

### 專22. B7. 社區資源聯結及運用情形

- **負責職務**：社工
- **審查方式**：文件檢閱、現場訪談


**評鑑基準：**

1. 訂有社區資源聯結及運用之相關計畫及鼓勵、協助服務對象參與社區交流或宣導服務之策略
2. 接受社區團體進入服務單位辦理交流活動
3. 各項活動均留有紀錄（含活動辦理時間、參加成員、活動內容、活動過程、量與質之評值成果、活動照片等）
4. 建立三處以上之多元化社區相關服務網絡（如志工人力資源、醫療資源、福利資源、經濟補助資源、社區關懷據點等資料檔案），並定期盤點、更新

### 專23. B8. 與家屬互動及提供服務情形

- **負責職務**：社工
- **審查方式**：文件檢閱、現場訪談


**評鑑基準：**

1. 訂有家屬教育之年度計畫，內容需含機構防災、公共安全議題宣導，及鼓勵家屬與服務對象互動之策略
2. 家屬與服務對象互動（如家屬探訪或服務對象外出與家屬聚會）須留有紀錄
3. 每年至少辦理2次以上符合主題之家屬教育或家屬座談會或聯誼活動，並留有相關文件（含簽到單、活動紀錄等）
4. 每季至少1次與每位服務對象之家屬電訪或會談了解其需要（無家屬者除外），提供支持服務並有紀錄

### 專24. B9. 提供服務對象例行及必要之醫療服務情形

- **負責職務**：護A
- **審查方式**：文件檢閱、現場訪談；檢閱機構與特約醫療院所訂定之合約；抽查至少5位服務對象醫師評估紀錄；請教服務對象醫師巡診情形


**評鑑基準：**

1. 聘有特約醫師或與醫療院所訂有診察（巡診）服務及緊急後送合約
2. 新入住服務對象須於1個月內完成醫師診察及評估工作，並有醫療診療服務紀錄

- **審查方式**：實地察看；察看每間寢室採光、照明及通風；察看公共空間採光、照明及通風；查驗溫控設備


**評鑑基準：**

1. 每間寢室都有自然採光及照明設備，且通風佳，無異味
2. 公共空間有良好採光及照明設備，且通風佳，無異味（公共空間係指寢室以外，服務對象可活動的空間含走道）
3. 可依服務對象不同溫度需求，於寢室提供調整冷暖之設備
4. 寢室配置可調整光度之照明燈具
5. 未靠窗之公共空間，有充足人工照明
6. 未靠窗之公共空間，有充足空調設備

### 安49. C2. 儲藏設施設置情形

- **負責職務**：環安
- **審查方式**：實地察看、文件檢閱；察看儲藏空間或設施是否設於機構立案處；檢視定期整理紀錄


**評鑑基準：**

1. 具有輔具、傢俱、個人物品或消耗性物品之儲藏空間
2. 易燃或可燃性物品、被褥、床單存放櫃及雜物之公共儲藏空間，應有密閉性且隨時上鎖
3. 儲藏室及儲存易燃或可燃性物品之房間，應建置適用之火警探測器或自動撒水設備
4. 各儲存物品之空間具分類標示及擺放整齊，定期盤點並有紀錄

### 安50. C3. 日常活動空間（如餐廳、閱覽區、活動區、會客區）及設施、設備設置情形

- **負責職務**：環安
- **審查方式**：實地察看、現場訪談；確認餐廳設施符合規定；察看各類日常活動空間設置；確認每樓層有活動空間


**評鑑基準：**

1. 餐廳設置區位符合便利性，其設施設備、動線，可滿足服務對象之需求
2. 日常活動空間之位置符合服務對象使用之需求及便利性，且每週至少一次清潔環境，並有紀錄
3. 日常活動空間有足夠之設施設備，滿足服務對象交誼所需
4. 每樓層均有活動空間

### 安51. C4. 寢室及浴廁緊急呼叫系統設置情形（一級必要）

- **負責職務**：環安
- **審查方式**：現場察看；現場察看浴室、廁所及寢室緊急呼叫設備設置情形；現場測試設備功能


**評鑑基準：**

1. 浴室、廁所及寢室應設有緊急呼叫設備
2. 緊急呼叫設備功能正常
3. 緊急呼叫設備，設置位置適當
4. 有人按鈴，服務人員能立即反應處理（浴室、廁所測試時應在關門情況下按鈴）

### 安52. C5. 昇降機（電梯）設置情形（二級加強）

- **負責職務**：環安
- **審查方式**：實地察看；確認昇降機符合建築物無障礙設施設計規範；或符合既有公共建築物無障礙設施替代改善計畫


**評鑑基準：**

1. 每幢2層樓以上建築物應至少設置1座無障礙昇降機；昇降機門的淨寬度不得小於90公分，機廂之深度不得小於135公分
2. 昇降機設有點字之呼叫鈕前方30公分處之地板，應作30公分×60公分之不同材質處理
3. 昇降機前方梯廳之輪椅迴轉空間，有直徑150公分以上之輪椅迴轉空間
4. 點字設施、標誌及輪椅乘坐者之操作盤
5. 至少二側設置扶手
6. 未設置昇降機，但無障礙通路（或其替代改善設施）可到達之房間數超過總房間數50%以上者

### 安53. C6. 無障礙浴廁及洗澡設備之設置與使用情形（二級加強）

- **負責職務**：環安
- **審查方式**：實地察看；每幢建物至少設置1處無障礙浴廁；依建照領取日期適用不同版本建築技術規則


**評鑑基準：**

1. 出入口高差、寬度、門開關方式及地面材料止滑（無障礙廁所及浴室出入口應無高差，若有高差應設置坡道或昇降設備）
2. 設置扶手協助變換姿勢及防止滑倒
3. 輪椅之迴轉空間，馬桶之設計與空間足供可自行使用輪椅者橫向移坐，具有扶手
4. 洗臉盆及鏡子
5. 多人使用之浴廁，應有適當的隔間或門簾（無障礙浴室及廁所合併設置者，應有適當隔間且不可上鎖）
6. 至少設置兩處求助鈴

### 安54. C7. 餐廳、廚房之設施設備與環境清潔衛生情形（二級加強）

- **負責職務**：護B
- **審查方式**：實地察看、文件檢閱；察看廚房衛生及食材儲存；查核食物留存檢體；確認有效期限合約


**評鑑基準：**

1. 【自辦伙食】訂有廚房作業標準（至少應包含設施設備之清潔、檢查、垃圾及廚餘之處理方式）及食材儲存之作業標準，且落實每日環境管理並有紀錄
2. 餐廳環境維持清潔，且有定期清掃及消毒之紀錄
3. 具乾貨、冷凍（-18℃以下）及冷藏（7℃以下）食材之設備，且生、熟食材分開儲存管理，並有進貨及定期檢查之紀錄（自辦伙食）
4. 食物檢體留存（整份或每樣食物150公克）分開封裝，標示日期及餐次，冷藏存放48小時
5. 洗碗及洗菜應分槽處理（自辦伙食）；供膳外包應有GHP稽查紀錄或HACCP合格證明

### 安55. C8. 污物、事業廢棄物處理及環境病媒、蟲害防治情形

- **負責職務**：護B
- **審查方式**：文件檢閱、實地察看；察看污物處理空間及動線；查核消毒紀錄、廢棄物處理合約及病媒防治文件


**評鑑基準：**

1. 訂有機構污物處理辦法及流程
2. 有獨立之污物處理空間；污物處理及動線，符合感染管制原則（動線避免直接穿越用餐區和備膳空間）
3. 機構內外環境清潔且無異味；每3個月機構內外環境消毒1次並有紀錄
4. 備有效期內廢棄物委託處理合約
5. 廢棄物定時清理、定點存放且有專人處理，依廢棄物清理法規範進行分類
6. 有具體杜絕蚊蟲害之防治措施及設施（如紗窗、紗門等）
7. 每半年委外合格之病媒防治業做病媒、害蟲防治，應有佐證文件

### 安56. C9. 建築物公共安全檢查簽證申報及消防安全設備設置、檢修及防火管理情形（一級必要）

- **負責職務**：環安
- **審查方式**：文件檢閱、現場訪談；檢閱消防申報紀錄及前2次完整申報資料；確認防火管理制度；抽測自衛消防編組人員職責瞭解情形


**評鑑基準：**

1. 建物現況與使用執照登載用途相符，並依規定辦理建築物防火避難設施與設備安全檢查簽證申報；現場置有檢查報告書及地方政府核發之審查合格證明文件
2. 依規定每半年委託消防設備師或消防設備士定期檢修消防安全設備，其檢修結果依限報請當地消防機關備查，並備有前2次完整申報紀錄
3. 建立防火管理制度，且工作人員了解自身職責
4. 擔任防火管理人之人員應符合消防法施行細則第14條規定，且由社工、醫事人員、照顧服務員以外之管理或監督層次人員擔任
5. 機構應每個月自主檢查機構內部用電設備安全，並有符合現況之紀錄
6. 機構應每半年一次委託用電設備檢驗維護業者定期檢驗機構內部用電設備，並有紀錄

### 安57. C10. 疏散避難系統及等待救援空間設置（一級必要）

- **負責職務**：環安
- **審查方式**：實地察看；確認逃生路徑暢通；測試防火門功能；確認等待救援空間設置


**評鑑基準：**

1. 樓梯間、走道、出入口、防火門應保持暢通無阻礙物；安全梯出入口、防火區劃之防火門出入口等周圍1.5公尺地面應保持淨空
2. 逃生路徑為雙向（其中具備一座安全梯及兩個以上避難途徑）
3. 設置逃生路徑之防火門應往避難方向開啟並隨時保持關閉，或能與火警自動警報設備連動而關閉，且不需鑰匙即可雙向開啟
4. 設有等待救援空間並有適當煙控功能，或依法設有防火區劃
5. 火災時，中央空氣調節系統之電源開關能和火警自動警報設備連動而自動切斷，防止火煙蔓延

### 安58. C11. 訂定符合機構特性及需要之緊急災害應變計畫（EOP）及作業程序，並落實演練（一級必要）

- **負責職務**：環安
- **審查方式**：文件檢閱、現場訪談；檢閱緊急災害應變計畫、演練腳本、演練紀錄（含照片）、演練後檢討會議紀錄


**評鑑基準：**

1. 對於火災、風災、水災、地震、停電及停水等緊急災害，訂有符合機構與災害特性之緊急災害應變計畫與作業程序，並應納入119火災通報裝置及自動撒水設備之因應方式
2. 完備之緊急聯絡網及災害應變啟動機制，及具有適當的人力調度及緊急召回機制
3. 訂有防火及避難安全風險自主檢核計畫，落實執行並有紀錄
4. 應每年實施緊急災害應變演練2次，包括複合型緊急災害應變演練1次及夜間演練1次，並有演練之過程、檢討改善方案、紀錄（含照片）

### 安59. C12. 訂定符合機構住民之疏散策略及持續照顧作業程序，並落實照顧人力之緊急應變能力（一級必要）

- **負責職務**：環安
- **審查方式**：文件檢閱、現場訪談；檢閱緊急避難平面圖；確認逃生圖標示正確；抽測工作人員操作設施設備及疏散方式


**評鑑基準：**

1. 機構應於各樓層出入口張貼緊急避難平面圖（或逃生圖，至少A3尺寸），明確訂定各樓層住民疏散運送之順序與策略
2. 緊急避難平面圖（或逃生圖）應具比例及適當大小，且標示所在位置並與機構現場方向、方位符合
3. 應於各層出入口、梯間張貼符合比例、方位，可供消防搶救辨識之圖面（應註記現在位置、消防栓箱、等待救援空間等）
4. 安排防火管理人、照顧服務員（含外籍）、護理人員、替代役、家屬自聘看護工參與災害風險辨識、溝通及防救災之教育訓練，並落實應變救援能力

### 安60. C13. 隔離空間設置及使用情形

- **負責職務**：護B
- **審查方式**：文件檢閱、實地察看；檢閱隔離空間使用規定；察看是否設置隔離空間及其動線；確認獨立空調、衛浴設備符合感染管制原則


**評鑑基準：**

2. 隔離空間、位置符合感染管制相關規定
3. 明確規範隔離空間使用對象（適用對象為新入住或出院或疑似感染個案）
4. 訂有各類隔離措施標準作業流程（應包含呼吸道、泌尿道、腸胃道、皮膚性感染、住民轉換之消毒等項目），並依個案需求提供合宜的隔離照護技術

### 安61. C14. 設備、儀器維護及辦理人員操作訓練情形

- **負責職務**：護B
- **審查方式**：文件檢閱、現場訪談、現場抽測；確認設備儀器定期維護及校正；現場訪問及抽測工作人員操作情形（設備包括床、輪椅、抽痰機、血壓計、製氧機及電器用品等）


**評鑑基準：**

1. 訂有設備、儀器定期維護之相關作業規定及人員操作訓練辦法
2. 廠商對於儀器設備有維護或定期校正之機制，並有紀錄
3. 於購入新設備及平時教育訓練時安排相關設備、儀器操作課程，並有紀錄
4. 定期查核各類設備、儀器操作技術，並備有紀錄

### 安62. C15. 護理站設施設備設置情形（一級必要）

- **負責職務**：護A
- **審查方式**：文件檢閱、現場抽測；檢閱相關檢查保存紀錄；抽驗工作人員各項用物熟悉度及急救設備功能；訪談藥品及衛材保存管理情形


**評鑑基準：**

1. 護理站應有基本急救設備（氧氣、鼻管、人工氣道、氧氣面罩、抽吸設備、喉頭鏡、氣管內管、甦醒袋、常備急救藥品）、準備室、護理紀錄櫃、藥品及醫療器材存放櫃、工作台、治療車、洗手設備及輪椅
2. 各項設備定期維護且功能正常，藥品須在效期內（氧氣鋼瓶期限需注意）
3. 每層樓設護理站或簡易護理工作站（機構內至少設有一處護理站）

### 安63. C16. 機構飲用供水設備安全及清潔情形（二級加強）

- **負責職務**：環安
- **審查方式**：文件檢閱；檢閱水塔、飲水機清潔保養紀錄；查驗飲用水檢驗報告（需委託主管機關認可之水質檢驗業者）


**評鑑基準：**

1. 自來水塔每半年定期清潔保養並有紀錄
2. 自來水經飲用水設備處理後水質，每3個月檢測水質之大腸桿菌群，且有檢驗報告
3. 非使用自來水者，須經飲用水設備處理，每3個月檢測水質之大腸桿菌群，其水源每3個月加測硝酸鹽氮及砷
4. 使用包裝用水者，需附水質檢驗合格證明，並須在有效期限內，且應置放於陰涼處
5. 飲水機每月定期檢查保養並有紀錄；使用濾芯者應依產品說明書備註日期更換濾芯，若無規定每3個月更換一次

## D、個案權益保障（權）

### 權64. D1. 服務對象個案資料管理、統計分析與應用及保密情形（二級加強）

- **負責職務**：社工
- **審查方式**：基本資料檢閱、現場訪談；與負責人員現場會談及操作；檢閱服務對象資料之統計及分析文件（管理系統以衛福部長照機構暨長照人員相關管理資訊系統為主）


**評鑑基準：**

1. 管理系統者明確訂定各使用者之權限，確保服務對象資料不外洩
2. 訂有服務對象管理系統之管理辦法（參照個人資料保護法，並包含肖像權同意書、借用標準及流程）
3. 對於服務對象管理系統之資料進行統計、分析，並配合衛生福利部政策上傳照顧服務資料，且隨時更新內容
4. 統計分析結果，有具體因應或改善措施，並作為內部改善品質之參考

### 權65. D2. 與入住委託人訂立契約情形

- **負責職務**：社工
- **審查方式**：文件檢閱、現場訪談；檢視契約資料（契約應核章完整）；與主任（院長）及服務對象會談契約內容事項


**評鑑基準：**

1. 應與委託人（本人或家屬、監護人、代理人）訂立契約

4. 當相關法規、服務對象、服務提供者條件變更時應更換契約

### 權66. D3. 服務對象生活注意事項及家屬來訪注意事項訂定情形

- **負責職務**：社工
- **審查方式**：文件檢閱、現場訪談、現場察看；訪問服務對象有關生活注意事項內容


**評鑑基準：**

1. 訂有服務對象生活注意事項及家屬來訪注意事項
2. 前項注意事項應清楚告知服務對象及家屬並有紀錄，且於明顯處公告
3. 若有違反注意事項，應有處理或調整，並有紀錄
4. 依服務對象或家屬的狀況或反應適時處理或調整（服務對象生活注意事項允許服務對象可自由和外界溝通）

### 權67. D4. 服務對象或家屬申訴意見反應辦理情形

- **負責職務**：社工
- **審查方式**：文件檢閱、實地察看、現場訪談；檢視申訴處理流程；實地觀察申訴管道設置；請教服務對象是否清楚申訴流程


**評鑑基準：**

1. 意見反應及申訴處理流程（含申訴管道），應張貼於機構明顯處，且明確告知服務對象及家屬
2. 設置合適的意見反應/申訴管道
3. 有專人處理意見反應及申訴案件，申訴處理結果應回覆申訴者，並有紀錄
4. 每年分析意見反應及申訴案件，留有紀錄及追蹤

### 權68. D5. 尊重服務對象信仰情形

- **負責職務**：社工
- **審查方式**：文件檢閱、實地察看、現場訪談；檢視個別靈性關懷服務紀錄；訪問機構服務對象


**評鑑基準：**

1. 尊重服務對象宗教信仰
2. 服務對象擁有自行決定參與宗教活動的機會
3. 有提供靈性關懷服務，並有服務紀錄
4. 有簡易宗教設施，並實際提供服務對象使用

### 權69. D6. 居家情境佈置情形（二級加強）

- **負責職務**：社工
- **審查方式**：實地察看；現場察看服務對象之個人物品擺放情形；現場察看機構個人空間是否具隱私性


**評鑑基準：**

1. 個人空間隱私之維護，床與床之間應具隔離視線之屏障物（如圍簾）
2. 個人空間隱私之維護，監視器未設置於服務對象寢室及浴廁內
3. 床位旁有可擺放私人物品的櫥櫃或床頭櫃
4. 允許服務對象可攜帶個人物品，佈置自己的空間環境，且不危及公共安全

### 權70. D7. 服務對象財物管理及死亡遺產處理情形

- **負責職務**：社工
- **審查方式**：文件檢閱、現場訪談；檢閱財產管理資訊、執行及稽核紀錄；現場訪談服務對象是否知悉相關規定


**評鑑基準：**

1. 訂有服務對象財物管理（如退休金或零用金代墊、代購費用管理、信託管理、重要財物保管、死亡遺產處理等）辦法
2. 清楚告知服務對象及家屬相關規定並有紀錄
3. 有專人協助處理且有紀錄

### 權71. D8. 提供緩和醫療及臨終照護措施

- **負責職務**：社工
- **審查方式**：現場訪談、文件檢閱；檢閱機構提供之緩和醫療相關資訊及臨終照護流程；訪談提供臨終關懷之人員


**評鑑基準：**

1. 提供服務對象或家屬安寧緩和醫療（如不施行心肺復甦術簽立、維生醫療抉擇）或病人自主權利法（如預立醫療決定、預立醫療照護諮商）相關資訊
2. 訂有前述安寧緩和醫療或病人自主權利法相關處理之作業流程規範、步驟，且訂有鼓勵服務對象或家屬針對DNR共同討論共識決定的機制
3. 訂有已簽訂DNR及未簽訂DNR的處理作業流程，並有實際案例
4. 提供服務對象或家屬臨終照護關懷相關處理流程或手冊
5. 協助家屬處理喪葬事宜，並有紀錄

### 權72. D9. 辦理服務滿意度調查情形

- **負責職務**：社工
- **審查方式**：文件檢視、現場訪談；檢閱調查問卷及改善方案內容；與家屬或服務對象訪談


**評鑑基準：**

1. 每年至少辦理1次不具名滿意度調查
2. 滿意度調查包含服務內容、服務人員態度、設施設備等項目
3. 有調查分析報告
4. 依據調查結果分析及檢討，提出改善之措施

## E、服務改進創新（創）

### 創73. E1. 前次評鑑建議事項改善情形

- **負責職務**：行政
- **審查方式**：文件檢閱、現場訪談；與主任（院長）現場會談；檢閱改善情形相關文件；請主任（院長）說明改進內容及成效


**評鑑基準：**

1. 針對前次評鑑之改進事項擬訂具體改進措施，確實執行，並有成效或說明無法達成改善目標之原因
2. 改善比例達80%以上（第1次接受衛福部評鑑者，以機構接受地方政府最近1次評鑑建議改善事項為主；亦未曾接受地方政府評鑑者，本項不適用）

### 創74. E2. 創新或配合政策創新或特色相關措施執行

- **負責職務**：行政
- **審查方式**：文件檢閱、現場訪談；由評鑑委員共識決，每項0.5分，最多加總分3分


**評鑑基準：**

1. 提供具有創新或特色之相關措施，包括：服務對象安全（如優於法令之更高規格之設施設備等）、特殊族群創新照護服務模式、配合（參與）政策或試辦等相關計畫至少1項
2. 前述服務具有具體實蹟（成效）
3. 配合政策可包含：加入防災社區計畫、配合政府辦理防災演練示範觀摩、每年緊急災害應變演練4次、收治照護愛滋感染者、外籍照服員每年在職訓練達6小時以上（70%以上）、協助緊急安置及收容弱勢個案等

### 創75. E3. 評鑑期間之違規及重大負面事件紀錄

- **負責職務**：行政
- **審查方式**：現場訪談、文件檢閱；由主管機關提供違規證明及重大負面事件資料


**評鑑基準：**

1. 評鑑期間有違規事項，經查證屬實者（如於未經許可立案範圍收容、對服務對象不當對待等及其他經主管機關認定違規事項）
2. 重大負面事件（如機構內性侵害、工作人員對服務對象施暴、公共安全意外等及其他經主管機關認定事件）
3. 本項於總分外扣分；依「臺北市老人安養暨長期照顧機構評鑑計分方式及評等原則」辦理
