# 一般護理之家 評鑑基準

> 115年度一般護理之家評鑑基準

## A、行政組織、經營管理與服務對象權益保障（A）

### A1. A1.1 機構負責人實際管理行政作業與照護品質

- **負責職務**：負責人
- **審查方式**：資料查核


**評鑑基準：**

1. 負責人每月至少1次至機構查看實際照護情形並有書面紀錄
2. 護理人員符合護理人員法規定，持有效執照執業，且與雇用機構相符
3. 每位護理人員照顧住民數符合規定（日班≤9人，夜班≤15人）
4. 訂有護理人員在職訓練計畫並確實執行，每年至少16小時

### A2. A1.2 專任人員配置及急救訓練情形

- **負責職務**：負責人/護理主管
- **審查方式**：資料查核


**評鑑基準：**

1. 依法設有護理主管（護理長）並符合資格
2. 護理人員急救訓練符合規定（每2年1次，8小時以上，含BLS、AED）
3. 訂有新進護理人員訓練計畫並確實執行
4. 照顧服務員依規定配置，且持有照顧服務員訓練結業證明書

### A3. A1.3 意外或緊急事件處理流程及執行情形

- **負責職務**：負責人/護理主管
- **審查方式**：資料查核


**評鑑基準：**

1. 訂有意外事件（跌倒、壓傷等）處理流程並確實執行
2. 意外事件發生後24小時內通報，且有追蹤改善措施
3. 訂有緊急醫療（急救）處理流程並確實執行
4. 護理人員熟知緊急事件處理流程，實地抽測

### A4. A2.1 防疫機制落實執行及檢討改善

- **負責職務**：感控負責人/護理師
- **審查方式**：資料查核


**評鑑基準：**

1. 訂有感染管制計畫並確實執行
2. 訂有傳染病及新興感染症防疫機制並定期演練
3. 住民及工作人員傳染病監測有紀錄，且有追蹤改善機制
4. 工作人員依規定完成感染管制教育訓練（每年至少6小時）

### A5. A2.2 推動安寧緩和療護及病人醫療自主權

- **負責職務**：負責人/社工
- **審查方式**：資料查核


**評鑑基準：**

1. 提供住民及家屬安寧緩和療護相關資訊與諮詢
2. 尊重住民意願，協助辦理預立醫療決定（AD）或安寧緩和意願書
3. 工作人員接受安寧緩和療護教育訓練
4. 建立安寧緩和療護轉介機制

## B、專業服務與生活照顧（B）

### B6. B1 住民服務需求評估及確實依評估結果執行照護計畫

- **負責職務**：護理師/護理長
- **審查方式**：資料查核


**評鑑基準：**

1. 新收住民於入住24小時內完成初步護理評估，72小時內完成完整評估
2. 依評估結果訂定個別化照護計畫，並有跨專業團隊成員簽名
3. 照護計畫至少每3個月評估修訂1次，或依住民狀況變化隨時修訂
4. 抽查照護計畫與實際照護措施符合程度

### B7. B2 提供住民整合性照顧並定期檢討執行成效

- **負責職務**：護理長/跨專業團隊
- **審查方式**：資料查核


**評鑑基準：**

1. 定期（至少每3個月）召開跨專業照護計畫會議並有紀錄
2. 住民及家屬參與照護計畫討論
3. 整合醫療、護理、復健、營養等各專業服務，提供全人照顧
4. 定期評估住民ADL、認知功能等，並依結果調整照護計畫

### B8. B3 訂有品質監測指標並定期檢討執行成效

- **負責職務**：護理長/品管
- **審查方式**：資料查核


**評鑑基準：**

1. 訂有護理品質監測指標（含跌倒、壓傷、導管感染等）並定期蒐集
2. 品質監測資料每季彙整分析，並有檢討改善措施
3. 品質改善成效有追蹤紀錄
4. 辦理品質相關教育訓練，提升工作人員品質意識

## C、環境設施與安全維護（C）

### C9. C1 災害緊急應變計畫及作業程序符合機構及住民需要並落實演練

- **負責職務**：負責人/防火管理人
- **審查方式**：資料查核＋實地查核


**評鑑基準：**

1. 訂有災害緊急應變計畫（含火災、地震、颱風等），內容符合機構及住民需要
2. 每年至少辦理2次消防演練（含夜間演練1次）
3. 工作人員熟知疏散程序及職責
4. 消防安全設備（灑水系統、滅火器、警報系統等）定期維護保養有紀錄

### C10. C2 疏散避難系統及等待救援空間設置

- **負責職務**：行政/設施管理
- **審查方式**：實地查核


**評鑑基準：**

1. 疏散避難通道保持暢通，無障礙物堆積
2. 設有等待救援空間（防火區劃）並有明確標示
3. 疏散指示標誌清晰可見，緊急照明設備功能正常
4. 住民床位配置合理，利於緊急疏散作業

### C11. C3 疏散策略及持續照顧作業程序並落實教育訓練

- **負責職務**：防火管理人/護理師
- **審查方式**：資料查核＋實地查核


**評鑑基準：**

1. 依住民失能程度訂有個別化疏散策略（行走、輪椅、擔架等）
2. 訂有疏散後持續照顧作業程序（含醫療、用藥、飲食等）
3. 工作人員接受疏散策略教育訓練並有紀錄
4. 實地抽測工作人員執行疏散策略之能力

### C12. C4 情境式火災風險辨識與溝通並依情境實地抽測演練

- **負責職務**：負責人/護理師
- **審查方式**：實地查核（情境演練）


**評鑑基準：**

1. 依不同起火位置訂有情境式疏散計畫
2. 工作人員能正確辨識火災風險並執行相對應疏散措施
3. 實地情境演練：抽測工作人員依指定情境執行疏散
4. 住民了解緊急疏散信號及基本自救原則（依能力評估）

## D、特別事項（D）

### D13. D1 創新或配合政策執行

- **負責職務**：負責人
- **審查方式**：資料查核


**評鑑基準：**

1. 推動創新服務或配合政府政策執行，有具體成效
2. 參與衛生主管機關辦理之相關計畫或試辦方案
3. 創新服務或政策執行成果有書面紀錄及成效評估
4. 鼓勵工作人員參與創新服務發展

### D14. D2 強化住民口腔健康照護

- **負責職務**：護理師/照服員
- **審查方式**：資料查核


**評鑑基準：**

1. 定期評估住民口腔健康狀況，訂有口腔照護計畫
2. 工作人員接受口腔照護技能訓練並確實執行
3. 協助住民每日口腔清潔，有執行紀錄
4. 建立與牙科醫療資源之轉介機制

### D15. D3 其他重大異常情事（試評扣分項）

- **負責職務**：負責人
- **審查方式**：資料查核


**評鑑基準：**

1. 評鑑期間無發生重大醫療事故且未依規定通報
2. 評鑑期間無發生違法情事（如超收費用、違規廣告等）
3. 評鑑期間無住民人權侵害事件
4. 配合評鑑作業，提供正確完整資料
