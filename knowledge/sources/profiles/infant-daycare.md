# 托嬰中心 評鑑基準

> 臺北市114-116年度托嬰中心評鑑指標

## 一、行政管理 ▸ 立案行政與業務管理（管）

### 管1. 行政管理配合事項

- **負責職務**：負責人/主管人員
- **審查方式**：實地觀察、查閱及檢視相關資料及網站登錄情形、訪談負責人及主管人員


**評鑑基準：**

1. 工作人員定期體檢（含負責人、專任及兼任人員每2年體檢1次；廚工每1年體檢1次）
2. 如實上網更新異動兒童及工作人員資料，登錄資料應與實際收托兒童及所聘工作人員名冊相符
3. 依法投保兒童團體保險；並定期投保公共意外責任險及火險
4. 依主管機關核定之收退費標準確實執行，並公告周知家長
5. 監視器設備定期檢核、保養管理及維護
6. 訂定及宣導性騷擾防治、申訴及懲戒措施

### 管2. 員工在職訓練

- **負責職務**：負責人/主管人員
- **審查方式**：查閱及檢視相關資料及網站登錄情形、訪談負責人及主管人員


**評鑑基準：**

1. 主管人員及托育人員每年完成18小時以上在職訓練
2. 其他工作人員每人每年至少參與4小時相關在職訓練

### 管3. 嬰幼兒資料與接送管理

- **負責職務**：行政人員
- **審查方式**：實地觀察、檢視嬰幼兒基本資料（綜合資料表），含姓名、居家概況、其他重要資訊


**評鑑基準：**

1. 建立每位嬰幼兒基本資料，內容詳細
2. 確實填寫完整、適時更新
3. 建立接送辦法，確實執行
4. 建立出缺席紀錄，對缺席嬰幼兒進行追蹤聯繫

## 一、行政管理 ▸ 人事領導與管理（人）

### 人4. 人事規章與差假管理

- **負責職務**：負責人/主管人員
- **審查方式**：訪談主管人員、托育人員及其他工作人員、檢視組織系統表及工作執掌表


**評鑑基準：**

1. 訂有合宜權利義務的人事規章或工作手冊，公告並發給員工參存
2. 依人事規章或工作手冊確實執行
3. 每位托育人員清楚照顧的責任、分工及交接方式，並確實執行
4. 依據勞動基準法、性別平等工作法等相關勞動法規訂定差假辦法
5. 依所訂定差假辦法確實執行

### 人5. 員工薪資、保險與退休

- **負責職務**：負責人/主管人員
- **審查方式**：訪談主管人員及其他工作人員、檢視並核對勞健保加保及勞退資料、薪資相關資料


**評鑑基準：**

1. 人事管理符合勞動基準法相關規定，且雇主應負擔或提撥之保費金額如實支應
2. 任職一年以上托育人員至少占2/3
3. 訂定薪資制度
4. 專職托育人員第一年投保薪資達每月30,300元以上
5. 給付員工工資一個月金額以上之年終獎金

## 一、行政管理 ▸ 文書與檔案管理（文）

### 文6. 家長手冊、行事曆與公文管理

- **負責職務**：行政人員
- **審查方式**：實地觀察、訪談主管人員及托育人員、檢視行事曆、家長通知單、托嬰機構訊息、檢視公文


**評鑑基準：**

1. 有編訂家長手冊並須知，並發給家長參存
2. 家長手冊或須知內容詳細確實，包含行政管理、托育活動、健康安全等，且內容符合實際情形
3. 定期訂定行事曆，且內容詳實，並公佈發給家長參考
4. 托嬰中心訊息定期或依實際需要以通知單或其他形式公佈並發給家長參存
5. 公文有適當方式公告相關人員週知，且依公文來文與發文的處理流程執行

### 文7. 召開會議

- **負責職務**：負責人/主管人員
- **審查方式**：訪談主管人員、托育人員及其他工作人員、檢視會議紀錄


**評鑑基準：**

1. 全體工作人員每半年確實參與會議至少一次
2. 定期召開會議及勞資會議，並留存紀錄
3. 會議紀錄內容詳細確實
4. 按照決議事項確實執行

## 一、行政管理 ▸ 財務、總務與安全管理（財）

### 財8. 財務與總務管理

- **負責職務**：行政人員
- **審查方式**：實地觀察與訪談、檢視帳冊等相關會計資料、申請採購登錄等相關總務資料


**評鑑基準：**

1. 有經費收支帳目
2. 設有完整詳細的財產清冊，並每年至少盤點一次
3. 設有物品管理流程並確實執行
4. 至少每半年進行整體環境安全檢核並留存紀錄
5. 依據檢核結果維修並有維修紀錄

### 財9. 事故傷害預防的行政措施

- **負責職務**：負責人/主管人員
- **審查方式**：實地觀察與訪談、查閱事故傷害流程、確認CPR證照及緊急聯絡人資料


**評鑑基準：**

1. 訂定事故傷害相關流程及紀錄表格
2. 電話旁備有緊急事故連絡電話，全體工作人員掌握嬰幼兒緊急聯絡人的資料
3. 專任工作人員均有急救證照
4. 有事故發生處理紀錄或機構內相關人員了解事故傷害處理流程

### 財10. 災害處理

- **負責職務**：負責人/主管人員
- **審查方式**：實地觀察與訪談、檢視火災及地震相關流程及表格、處理紀錄


**評鑑基準：**

1. 訂定相關流程及紀錄表格
2. 避難逃生路線圖正確，張貼合宜
3. 樓梯、走廊、出入口、通道等避難路線不得放置物品
4. 每半年辦理地震及火災之逃生避難演練

## 一、行政管理 ▸ 兒童權益保障（權）

### 權11. 兒童福利服務

- **負責職務**：負責人/主管人員
- **審查方式**：實地觀察與訪談、檢視收托辦法、優待減免辦法、收托名冊、通報紀錄


**評鑑基準：**

1. 訂定弱勢家庭及特殊需求嬰幼兒收托辦法並公告
2. 收托弱勢家庭及特殊需求嬰幼兒並給予優待及妥善照顧
3. 主動為家長提供政府相關補助資訊等文宣並協助辦理
4. 制訂托嬰中心內兒童保護通報處理流程及備有相關表格
5. 有通報紀錄或機構內相關人員了解兒童保護流程
6. 制訂托嬰中心內早期療育服務處理流程及備有相關表格
7. 有通報紀錄或機構內相關人員了解早期療育流程
8. 每年辦理或配合社區服務工作，提供實習、參觀、研究、觀摩等專業性活動

## 二、托育活動 ▸ 關係建立與互動（互）

### 互12. 安全依附與情緒照顧

- **負責職務**：托育人員
- **審查方式**：實地觀察及訪談托育人員與嬰幼兒的互動


**評鑑基準：**

1. 能經常性的擁抱或撫抱嬰幼兒
2. 能以愉悅、溫柔、正向的方式與嬰幼兒說話及互動
3. 能主動關心及合宜回應嬰幼兒個別的狀態
4. 能敏銳發現及適時回應嬰幼兒個別的情緒需求

### 互13. 溝通與互動

- **負責職務**：托育人員
- **審查方式**：實地觀察托育人員與嬰幼兒對話之語用、語速、語調與訪談托育人員


**評鑑基準：**

1. 能在不同情境中與嬰幼兒進行互動對話，促進嬰幼兒的語言發展
2. 能使用簡單明確的字詞、適當的速度、溫和的語調與嬰幼兒溝通
3. 對嬰幼兒的口語及非口語表達能等待且專注觀察、聆聽，並合宜回應
4. 能依嬰幼兒的發展營造同儕正向互動關係

### 互14. 團隊專業與協力

- **負責職務**：托育人員
- **審查方式**：實地觀察、查閱相關資料與訪談托育人員


**評鑑基準：**

1. 全體人員維持整潔、安全的裝扮與工作習慣
2. 全體人員以疼惜呵護的態度及穩定的情緒對待嬰幼兒
3. 嬰幼兒的基本照護由固定的托育人員負責
4. 托育人員具備支援、補位，共同照護嬰幼兒的主動性與默契

## 二、托育活動 ▸ 環境規劃與使用（環）

### 環15. 休息睡眠空間

- **負責職務**：托育人員
- **審查方式**：實地觀察、查閱相關資料與訪談托育人員


**評鑑基準：**

1. 睡眠區的規劃，提供嬰幼兒合宜的睡眠環境（床位間距30公分以上或以隔板區隔）
2. 睡眠區的設計，方便托育人員照護或引導嬰幼兒自行使用
3. 睡眠區內的設施設備，適合現有嬰幼兒之發展需求
4. 睡眠區的使用與維護情形，符合安全舒適之原則

### 環16. 餵食用餐空間

- **負責職務**：托育人員
- **審查方式**：實地觀察與訪談托育人員


**評鑑基準：**

1. 餵食用餐區的規劃，提供嬰幼兒合宜的用餐環境
2. 餵食用餐區的設計，方便托育人員照護或引導嬰幼兒自行使用
3. 餵食用餐區內的設施設備，適合現有嬰幼兒之發展需求
4. 餵食用餐區的使用與維護情形，符合安全舒適之原則

### 環17. 清潔盥洗空間

- **負責職務**：托育人員
- **審查方式**：實地觀察與訪談托育人員


**評鑑基準：**

1. 清潔盥洗區的規劃，能提供嬰幼兒合宜的清潔環境
2. 依法設置之清潔盥洗設備，方便托育人員照護或引導嬰幼兒自行使用
3. 清潔盥洗區內的設施設備，適合現有嬰幼兒之發展需求
4. 清潔盥洗區的使用與維護情形，符合安全舒適之原則

### 環18. 遊戲活動空間

- **負責職務**：托育人員
- **審查方式**：實地觀察與訪談托育人員


**評鑑基準：**

1. 活動區的規劃，提供嬰幼兒合宜的活動環境（多元化、動靜區隔、允許主動探索）
2. 活動區的設計，方便托育人員照護或引導嬰幼兒自行使用
3. 活動區內的設施設備，適合現有嬰幼兒之發展需求
4. 活動區的使用與維護情形，符合安全舒適之原則

### 環19. 環境舒適程度

- **負責職務**：托育人員
- **審查方式**：實地觀察、查閱相關資料與訪談托育人員


**評鑑基準：**

1. 活動室舒適不擁擠且通風良好
2. 活動室光線合宜（操作閱讀區350Lux以上，不得超過1000Lux）
3. 光線可局部調整並能回應嬰幼兒個別的需求
4. 活動室音量適中，可局部調整並能回應嬰幼兒個別的需求

### 環20. 遊戲設備使用安全

- **負責職務**：托育人員
- **審查方式**：實地觀察、查閱相關資料與訪談托育人員


**評鑑基準：**

1. 空間及遊戲設備使用能配合各項作息活動，維持安全及動線流暢
2. 遊戲設備的擺放及組合設計能符合嬰幼兒發展需求及安全原則
3. 經常保持嬰幼兒不離開視線的安全督導習慣
4. 教導及示範嬰幼兒維持安全合宜的生活常規，如行為舉止、使用工具等

### 環21. 遊戲設備與材料

- **負責職務**：托育人員
- **審查方式**：實地觀察、查閱相關資料與訪談托育人員


**評鑑基準：**

1. 遊戲設備與材料符合嬰幼兒月齡發展所需
2. 遊戲設備與材料數量充足（至少達托育嬰幼兒人數之3倍）
3. 遊戲設備與材料品質合宜（保持清潔、維護良好、完整無缺損、質地安全）
4. 遊戲設備與材料涵蓋不同材質

### 環22. 教玩具類型

- **負責職務**：托育人員
- **審查方式**：實地觀察、查閱相關資料與訪談托育人員


**評鑑基準：**

1. 提供嬰幼兒圖書（繪本、圖本及玩書）
2. 提供感官知覺與藝術創作類教玩具與材料
3. 提供身體動作類（含粗大動作與精細動作）教玩具與材料
4. 提供日常生活與扮演類教玩具與材料

### 環23. 情境設計

- **負責職務**：托育人員
- **審查方式**：實地觀察托育空間的情境佈置與查閱相關資料


**評鑑基準：**

1. 情境佈置符合嬰幼兒視線範圍
2. 情境設計能配合活動內容，定期更換
3. 情境設計，除了托育人員的設計之外，也包含嬰幼兒的參與
4. 情境設計能提供嬰幼兒生活觀察的機會

## 二、托育活動 ▸ 活動規劃與實施（活）

### 活24. 作息規劃與活動安排

- **負責職務**：托育人員
- **審查方式**：實地觀察、查閱各式活動實施紀錄（活動計畫、托育日誌、照片等）與訪談托育人員


**評鑑基準：**

1. 每日作息安排和緩、不急促，提供充裕的轉換時間，並依嬰幼兒需求彈性調整
2. 例行照護與活動安排應適齡適性，並符合嬰幼兒全人發展
3. 每日的遊戲學習型態，應動態、靜態均衡安排
4. 每週規劃實施戶外活動

### 活25. 餵食用餐

- **負責職務**：托育人員
- **審查方式**：實地觀察、查閱相關資料與訪談托育人員


**評鑑基準：**

1. 依嬰幼兒個別發展需求，採合宜的（個別或小團體）餵/進食方式，並備有紀錄
2. 維持輕鬆且愉快的餵/進食氣氛，不強迫餵食
3. 能依個別嬰幼兒當時情況，彈性安排餵/進食
4. 能協助嬰幼兒建立有益健康的飲食習慣

### 活26. 更換尿布

- **負責職務**：托育人員
- **審查方式**：實地觀察、查閱相關資料與訪談托育人員


**評鑑基準：**

1. 更換尿布符合標準流程（洗手→備妥→帶至尿布檯→清潔更換→離開→處理→清潔場地→洗手）
2. 過程與後續處理皆符合專業與衛生，能降低交互感染風險
3. 過程中符合安全原則、氣氛愉悅、互動正向（言語、表情等）
4. 更換尿布過程中，應依嬰幼兒個別狀況，保持執行的彈性

### 活27. 如廁練習

- **負責職務**：托育人員
- **審查方式**：實地觀察、查閱相關資料與訪談托育人員


**評鑑基準：**

1. 依嬰幼兒發展需求擬定如廁練習計畫
2. 能宣導並鼓勵家長共同執行如廁練習，並備有紀錄
3. 執行過程不強迫嬰幼兒，保持氣氛愉悅、互動正向
4. 如廁練習過程中，應依嬰幼兒個別狀況，保持執行的彈性

### 活28. 生活自理

- **負責職務**：托育人員
- **審查方式**：實地觀察是否提供生活自理練習機會、查閱相關資料與訪談托育人員


**評鑑基準：**

1. 能依嬰幼兒個別發展情形，養成清潔口腔、臉部的習慣
2. 能依嬰幼兒個別發展情形，養成清潔手部的習慣
3. 能依嬰幼兒個別發展情形，建立自行穿脫衣物的能力

## 三、健康安全 ▸ 健康管理（健）

### 健37. 體位測量

- **負責職務**：托育人員

**評鑑基準：**

1. 定期測量身高、體重、頭圍一次，並留有紀錄（1歲以下每月至少一次；1歲以上每兩個月一次）

- **負責職務**：托育人員

**評鑑基準：**

1. 嬰幼兒均依個別發展階段實施發展篩檢（臺北市學前兒童發展檢核表達百分之百）

### 健39. 健康管理

- **負責職務**：托育人員
- **審查方式**：查閱健康紀錄（含基本資料、疾病史、藥物與食物過敏紀錄等），執行達百分之百


**評鑑基準：**

1. 嬰幼兒均有完整的健康紀錄（含基本資料、疾病史、藥物與食物過敏紀錄、預防接種、發展篩檢結果等）
2. 生長及健康有異常之個案，協助處理或追蹤輔導

## 三、健康安全 ▸ 健康安全飲食（食）

### 食40. 餐點設計

- **負責職務**：廚工/行政人員
- **審查方式**：實地觀察與訪談托育人員、查閱各式活動實施紀錄


**評鑑基準：**

1. 依嬰幼兒發展需求，設計流質、半流質、半固體、固體等副食品及餐點
2. 半固體/固體餐點應以原型食物及多元烹調方式為原則
3. 提供食材需以多樣且均衡為原則
4. 餐點表定期公告給家長

### 食41. 食品選購及存放

- **負責職務**：廚工/行政人員
- **審查方式**：實地觀察（有一項過期食品則該項不給分）


**評鑑基準：**

1. 食材自然、新鮮；食品沒有過期
2. 食品分類、密封儲存
3. 食品及食器放置位置離牆、離地5cm
4. 食品與清潔劑等化學物品分開存放或食品放上層、清潔劑等化學物品放下層

### 食42. 餐點供應

- **負責職務**：廚工/行政人員
- **審查方式**：實地觀察與訪談托育人員


**評鑑基準：**

1. 提供餐點與設計餐點相符
2. 提供餐點的內容與份量合宜
3. 餐點溫度適當、備妥或運送時加蓋
4. 食物放置位置注意安全及衛生；避免直接用手接觸食物

### 食43. 飲水供應的品質

- **負責職務**：行政人員
- **審查方式**：實地觀察與查閱清洗水塔紀錄


**評鑑基準：**

1. 飲用水清潔衛生且溫度適當（每日以自來水煮沸並放置於清潔茶桶或開飲機定期清潔）
2. 符合嬰幼兒發展且清潔的練習杯、水杯
3. 練習杯、水杯擺放位置適當
4. 練習杯、水杯應使用耐高溫材質且確實消毒
5. 儲水塔定期清洗且有紀錄

### 食44. 食物樣品保存

- **負責職務**：廚工/行政人員
- **審查方式**：實地觀察副食品（以機構提供為主），包含所有入口之餐點（除市售包裝飲料）


**評鑑基準：**

1. 保存嬰幼兒食用之食物
2. 食物樣品密封、分開保存
3. 食物樣品日期標示清楚
4. 食物樣品置於冰箱冷藏室（7°C以下48小時）
5. 食物樣品保存48小時備查

## 三、健康安全 ▸ 環境與衛生設備（衛）

### 衛45. 廚房設備與環境

- **負責職務**：廚工/行政人員
- **審查方式**：實地觀察與訪談廚工


**評鑑基準：**

1. 清潔乾爽及通風良好
2. 照明光線應達100Lux以上；工作或調理檯面應持200Lux以上
3. 有生、熟食及水果專用且清潔的砧板、刀具（含剁刀、食物剪刀）且標示清楚，正確使用
4. 烹調用具及餐點盛裝容器清潔、儲放有序；餐點盛裝容器需定期消毒
5. 廚房有排油煙設備；垃圾桶加蓋

### 衛46. 冰箱清潔

- **負責職務**：廚工/行政人員
- **審查方式**：實地觀察（生食、熟食分類儲放）


**評鑑基準：**

1. 食品、食物密封且儲放有序，母乳有專用空間
2. 冰箱冷藏室及冷凍庫內均備有溫度計，且冷藏溫度0-7°C，冷凍室-18°C以下

### 衛47. 餐具

- **負責職務**：廚工/行政人員
- **審查方式**：實地觀察奶瓶/餐具消毒方式


**評鑑基準：**

1. 奶瓶/餐具應符合嬰幼兒發展且耐高溫材質
2. 奶瓶/餐具使用時符合清潔衛生原則，餐具確實消毒

### 衛48. 寢具

- **負責職務**：托育人員
- **審查方式**：實地觀察專用寢具、隔離收納、通風良好


**評鑑基準：**

1. 每位嬰幼兒均有專用的寢具，隔離收納且通風良好
2. 嬰幼兒之寢具保持整潔且定期清洗留有紀錄（每週定期清洗）

### 衛49. 嬰幼兒個人清潔用品

- **負責職務**：托育人員
- **審查方式**：實地觀察（個人清潔用品含水杯、牙刷、漱口杯、小毛巾、圍兜、尿布墊等）


**評鑑基準：**

1. 擺放位置適當
2. 個人用品保持清潔

### 衛50. 環境衛生

- **負責職務**：行政人員
- **審查方式**：實地觀察、查閱環境清潔定期消毒且紀錄完整


**評鑑基準：**

1. 整體環境衛生清潔
2. 機構有紗窗、紗門，蚊蠅無法進入
3. 機構環境定期清潔、消毒，並有紀錄
4. 空調及風扇設施有定期清潔紀錄

### 衛51. 浴廁衛生

- **負責職務**：行政人員
- **審查方式**：實地觀察乾手設備（個人用手帕、個人用毛巾、擦手紙、烘手機）


**評鑑基準：**

1. 通風、乾淨、無異味
2. 放置有蓋的垃圾桶
3. 有淨手及乾手設備
4. 地板具有確切防滑功能的措施

## 三、健康安全 ▸ 環境與設備安全（安）

### 安52. 預防跌倒墜落

- **負責職務**：托育人員
- **審查方式**：實地觀察全部的室內地板（含廁所內地板）


**評鑑基準：**

1. 地面平坦且不溼滑
2. 陽台、窗戶、樓梯等皆有防墜措施
3. 床、傢俱、尿布檯皆有防墜措施
4. 座椅穩固，不易傾倒

### 安53. 預防壓砸夾刺撞傷

- **負責職務**：托育人員
- **審查方式**：實地觀察全部的櫃子、桌子及牆壁，搖動各種櫃架確定其穩定性


**評鑑基準：**

1. 各種櫃架、桌子及物品安置穩固
2. 櫃架、桌椅、牆壁無銳角或突出物
3. 門、窗、抽屜、櫥櫃視嬰幼兒發展需求設置防夾裝置
4. 門、窗、櫥櫃視嬰幼兒發展需求設置防撞裝置

### 安54. 預防燒燙傷

- **負責職務**：托育人員
- **審查方式**：實地觀察廚房門使用柵欄或上鎖、插座以隱藏或置高方式處理


**評鑑基準：**

1. 有避免嬰幼兒進入廚房的措施
2. 插座有安全防護措施
3. 電器用品使用安全
4. 電器用品置於嬰幼兒無法碰觸的地方

### 安55. 預防窒息

- **負責職務**：托育人員
- **審查方式**：實地觀察窗簾拉繩使用收線盒或捲高、電線以隱藏或置高方式處理


**評鑑基準：**

1. 窗簾拉繩、電線有安全措施
2. 嬰幼兒的睡床、衣物未有繞頸的繩索（衣物繩長不超過15公分）
3. 嬰幼兒的棉被、枕頭適當（1歲以內應保持仰睡姿勢且不使用枕頭）
4. 教玩具、衣物附件無法吞食（直徑大於3.5cm或長度大於6cm）

### 安56. 預防中毒

- **負責職務**：托育人員
- **審查方式**：訪談工作人員採購原則及使用注意事項、查看相關證明


**評鑑基準：**

1. 教玩具的材質無毒且穩定
2. 電池放置及處理安全適當
3. 美勞素材皆採用無毒材料
4. 化學物品標示清楚，且適當存放
5. 無有毒植物或放置位置安全適當
6. 瓦斯桶、熱水器均裝置戶外、通風良好

### 安57. 遊戲場地與設備安全

- **負責職務**：托育人員
- **審查方式**：實地觀察室內、外大肌肉活動之遊戲場地、查閱檢核表及維修紀錄單


**評鑑基準：**

1. 遊戲場地地面平坦；四周牆面有適當防護措施
2. 遊戲設備下方地面有防護措施
3. 遊戲設備構造堅固，材質安全
4. 遊戲設備無破損且邊緣無尖銳物
5. 遊戲場地與遊戲設備每月至少一次檢核與維護紀錄

## 三、健康安全 ▸ 健康與安全照護（護）

### 護58. 保健設備

- **負責職務**：負責人/主管人員
- **審查方式**：實地觀察保健箱物品注意標示清楚、未過期，有專人管理且定期補充


**評鑑基準：**

1. 保健用品未過期，有八項以上（體溫計、無菌紗布、無菌棉枝、OK繃、繃帶、生理食鹽水、優碘、三角巾、固定板、熱水袋、冰枕等）
2. 保健用品有專人管理
3. 保健用品放置成人易取、嬰幼兒拿不到的地方
4. 不存放非醫囑藥物

### 護59. 藥品管理

- **負責職務**：托育人員
- **審查方式**：實地觀察與訪談工作人員、若機構無醫囑的藥物，本題不給分


**評鑑基準：**

1. 合理的託藥制度（含明文規定且公告家長，由家長填寫委託藥單）
2. 藥物（包含托育人員個人藥品）放置位置安全適當
3. 冰箱中有藥品專用區隔，並標示藥物使用者
4. 給藥方式須符合五對原則（嬰幼兒對、藥物對、劑量對、時間對、給藥途徑對）
5. 給藥紀錄完整

### 護60. 感染管控

- **負責職務**：負責人/主管人員
- **審查方式**：實地觀察及查閱傳染病宣導作業、查閱腸病毒與發燒等疑似群聚感染通報紀錄


**評鑑基準：**

1. 有傳染病防治宣導作業
2. 熟悉傳染病通報作業
3. 訂定感染管制措施（依衛生福利部疾病管制署公告最新版「托嬰中心感染管制手冊」修訂）
4. 傳染性疾病個案之隔離方式
