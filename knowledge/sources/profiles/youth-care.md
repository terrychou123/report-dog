# 兒少安置機構 評鑑基準

> 112年度兒童及少年安置機構評鑑指標

## 壹、行政組織與經營管理（管）

### 管1. 董(理)事會功能與運作

- **負責職務**：評鑑人員
- **審查方式**：審閱文件、機構人員訪談

- **配分**：2 分

**評鑑基準：**

1. 召開董(理)事會審議議事：(1)上年度決算書、業務執行書、收支餘絀表、資產負債表、經費運用情形概況表、基金存款證明、財產目錄等；(2)當年度預算書、業務計畫書等
2. 辦理董(理)事改選或改聘
3. 董(理)事會與機構權責劃分
4. 董(理)事會對於機構整體業務的瞭解與支持程度

### 管2. 機構行政組織架構與業務運作

- **負責職務**：評鑑人員
- **審查方式**：審閱文件

- **配分**：2 分

**評鑑基準：**

1. 行政例行業務會議（0.3分）
2. 行政組織架構（0.2分）
3. 建置資訊管理系統並確實填報衛生福利部社會及家庭署全國兒少安置及追蹤管理系統（1分）
4. 配合主管機關於時數內填報各項報表及依法檢具資料備查情形（0.5分）

### 管3. 員工手冊及人事制度

- **負責職務**：評鑑人員
- **審查方式**：審閱文件、機構人員訪談

- **配分**：2 分

**評鑑基準：**

1. 訂有員工手冊及職掌分工（0.4分）
2. 有明確之差勤管理及代理人制度，落實工作交接制度（0.4分）
3. 績效考核制度（0.4分）
4. 員工申訴制度（含性騷擾、性侵害防治、性別工作平等保障措施）（0.4分）
5. 薪資管理制度（0.4分）

### 管4. 人員資格與人數

- **負責職務**：主管機關
- **審查方式**：審閱文件、機構人員訪談

- **配分**：2 分

**評鑑基準：**

1. 依輔導查核表-組織管理第二項目「工作人員進用」(一)至(七)，經主管機關查有1項不符規定，則列扣1項缺失（惟於主管機關規定期限內完成改善者，則不列計缺失）（1分）
2. 專業人員稱定度：(1)流失率(0.5分)；(2)是否有久任獎勵制度(0.5分)（1分）

### 管5. 訓練進修

- **負責職務**：主管機關
- **審查方式**：審閱文件

- **配分**：1 分

**評鑑基準：**

1. 依輔導查核表-組織管理第六項目「專業人員訓練」，每年均符合規定（0.5分）
2. 所有專業人員（主管、社工人員、生輔人員、保育人員、托育人員及心輔人員等）每年都完成性侵害防治相關課程（0.5分）

### 管6. 勞動條件

- **負責職務**：主管機關
- **審查方式**：審閱文件

- **配分**：1 分

**評鑑基準：**

1. 依107年至108年輔導查核表-組織管理第八至九項目及109年至112年輔導查核表-勞動條件第一至三項目，每年均符合規定（1分）

### 特34. 因應COVID-19疫情防疫措施（最高+3分）

- **負責職務**：評鑑人員
- **審查方式**：審閱文件

- **配分**：3 分

**評鑑基準：**

1. 完備防疫機構應變計畫，並於疫情期間落實中央、地方政府相關規範（如體溫監測、快師等紀錄）（+1分）
2. 完備疫情期間工作人員因人力不足提早返工之返工計畫（+1分）
3. 兒少1、2劑基礎劑施打達8成；工作人員1、2、3劑基礎劑施打達9成（+0.5分）
4. 18歲以上兒少第3劑追加劑、工作人員第4劑追加劑施打達6成（+0.5分）

### 特35. 其他創新服務（最高+1分）

- **負責職務**：評鑑人員
- **審查方式**：審閱文件

- **配分**：1 分

**評鑑基準：**

1. 創新指機構內部相較於以往之服務或營運有明顯之發展性、突破性或創造性（如：營運模式創新、服務策略之創新、專業服務之研發、開發資源的策略或連結方式效果佳或具有創新性等）
2. 有完整之規劃並確實執行
3. 確實執行並具有成效
4. 有成效且賡續推廣
