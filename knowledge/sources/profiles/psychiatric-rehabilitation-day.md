# 精神復健機構（日間型） 評鑑基準

> 115年度精神復健機構評鑑基準－日間型機構

## 第1章、經營管理（1）

### 11. 1.1 機構負責人之經營管理

- **負責職務**：負責人
- **審查方式**：文件檢閱：機構理念、願景、任務、短中長程計畫、財務報表；現場訪談：負責人簡報

- **配分**：8 分

**評鑑基準：**

1. 負責人應運用「個人復元」及「社區支持」理念，發展對社區復健及經營理念，提出短中長程計畫及執行成效之說明
2. 具備財務規劃及管理能力，能提供員工優質福利與服務對象復健服務品質
3. 負責人應具正確社區復健理念，且熟知精神復健機構業務，並積極帶領員工落實執行
4. 短中長程計畫有提出具體之行動策略
5. 負責人上任至評鑑當年7月1日前，應滿1年

### 12. 1.2 專任工作人員人力穩定性

- **負責職務**：負責人/人事主管
- **審查方式**：文件檢閱：人事資料、留任率計算佐證

- **配分**：3 分
- **可免評**：是

**評鑑基準：**

1. 機構所有專任工作人員於過去4年，留任1年以上者超過60%以上
2. 有具體留任相關的激勵措施

### 13. 1.3 督導與教育訓練制度

- **負責職務**：督導/教育訓練負責人
- **審查方式**：文件檢閱：教育訓練計畫、督導紀錄；現場訪談：工作人員

- **配分**：3 分

**評鑑基準：**

1. 訂有年度工作人員教育訓練計畫，其中關於工作人員教育訓練課程內容，須包含身心障礙者權利公約（CRPD）、性別平等（如：CEDAW）、性侵害及性騷擾防治等議題，並落實執行
2. 工作人員應每月至少參加督導1次
3. 工作人員之精神照護工作年資於2年之內者，每月至少督導2次（其中1次應為個別督導）

### 14. 1.4 工作人員定期接受健康檢查情形

- **負責職務**：行政主管
- **審查方式**：文件檢閱：健康檢查紀錄、追蹤處理紀錄

- **配分**：3 分

**評鑑基準：**

1. 全體工作人員每年接受胸部X光及健康檢查，並備有紀錄
2. 新進人員應於到職前完成健檢
3. 健康檢查項目如有異常者，應備有追蹤輔導紀錄
4. 參與例行備餐或執行與食品製作有關之工作訓練其工作人員應同時依衛生福利部食品藥物管理署規範之檢查項目進行健康檢查

### 15. 1.5 社區便利性

- **負責職務**：負責人
- **審查方式**：文件檢閱：機構位置圖、交通資源說明；現場查看

- **配分**：3 分

**評鑑基準：**

1. 以學員步行15分鐘內可抵達市場、商店、車站或其他社區資源
2. 機構設置地點倘若沒有方便學員使用之大眾運輸工具，應提供符合學員便利交通需求之具體作為

### 16. 1.6 復健資源開發及運用

- **負責職務**：社工/復健專業人員
- **審查方式**：文件檢閱：復健資源清冊、運用紀錄

- **配分**：3 分

**評鑑基準：**

1. 復健資源符合學員訓練需求，清冊內容完整詳實，利於學員與工作人員參考使用
2. 運用相關資源，並有具體實例及紀錄
3. 每年資源盤點與檢討

### 17. 1.7 復健治療空間及設施

- **負責職務**：負責人
- **審查方式**：現場查看：復健治療空間、設施設備；文件檢閱：立案圖說

- **配分**：4 分

**評鑑基準：**

1. 配合學員復健規劃，提供適當的訓練空間及設備
2. 學員與工作人員可共同使用空間與設備無區分、區隔

### 18. 1.8 健身及康樂設施

- **負責職務**：負責人
- **審查方式**：現場查看：健身及康樂設施

- **配分**：2 分

**評鑑基準：**

1. 設施設備適當且符合學員需求並有常態性活動安排
2. 應有適當維護及安全措施

### 19. 1.9 前次評鑑建議事項辦理情形確實且具成效

- **負責職務**：負責人
- **審查方式**：文件檢閱：前次評鑑結果意見表、改善計畫及佐證資料

- **配分**：3 分
- **可免評**：是

**評鑑基準：**

1. 前次評鑑之建議改善事項有具體改善措施，並有相關佐證資料
2. 無法改善事項有確實說明，經查證屬實，且不影響學員之照顧安全
3. 改善措施確有成效

### 110. 1.10 評鑑資料填寫及實地評鑑簡報品質良好

- **負責職務**：負責人
- **審查方式**：文件檢閱：評鑑資料；現場觀察：簡報

- **配分**：2 分

**評鑑基準：**

1. 評鑑資料之填寫正確詳實且呈現實際經營管理與業務狀況
2. 實地評鑑時，應呈現前次評鑑當年度至此次評鑑前1個月之相關資料
3. 評鑑簡報內容精簡扼要，掌握時間與重點

## 第2章、復健服務（2）

### 211. 2.1 復健評估

- **負責職務**：專業人員
- **審查方式**：文件檢閱：復健評估表、評估工具、個案紀錄；現場訪談：專業人員

- **配分**：4 分

**評鑑基準：**

1. 提供適切之整合性復健評估，且運用實際或模擬情境進行評量
2. 專任管理人員應參與評估過程，且有簽名
3. 有完整收案評估，後續之評估則依學員復健目標達成狀況選擇評估工具及執行頻率
4. 整合性評估應納入自殺風險評估

### 212. 2.2 訂定復健目標及計畫

- **負責職務**：專業人員
- **審查方式**：文件檢閱：復健計畫、修正紀錄；現場訪談：學員、專業人員

- **配分**：4 分

**評鑑基準：**

1. 應依據「復健評估」結果訂定符合學員復健需求之計畫，內容具體可行並適時結合社區資源
2. 由專業人員、專任管理人員及學員共同擬訂，並有簽名紀錄
3. 至少每3個月修正1次
4. 學員均有其主責復健訓練之工作人員

### 213. 2.3 提供社區生活化之多元復健服務

- **負責職務**：專業人員
- **審查方式**：文件檢閱：復健服務紀錄、社區資源運用紀錄

- **配分**：4 分

**評鑑基準：**

1. 依據個別化之復健目標及計畫，提供社區生活所需之多元復健服務，並適時結合社區資源
2. 因應防疫或感染管制，於暫停服務期間，能透過電話、社群軟體及視訊會議或其他適當方式提供服務

### 214. 2.4 活動妥善規劃並定期修正

- **負責職務**：專業人員
- **審查方式**：文件檢閱：活動計畫書、活動紀錄；現場觀察

- **配分**：4 分

**評鑑基準：**

1. 活動安排符合不同功能學員之需求且結合運用社區資源提供各項活動
2. 有各項團體活動計畫書

### 215. 2.5 提供健康促進活動

- **負責職務**：專業人員
- **審查方式**：文件檢閱：健康促進活動紀錄；現場觀察

- **配分**：2 分

**評鑑基準：**

1. 依據2.1「復健評估」結果，充分運用機構內健身器材及結合社區運動設施，安排常態性體能活動
2. 有鼓勵全員參與之具體作為
3. 疫情期間，應有依疫情警戒等級而調整之健康促進活動，並訂有因應措施
4. 即時更新感染管制訊息，並確實執行

### 216. 2.6 提供工作復健訓練及轉銜服務

- **負責職務**：職能治療師/社工
- **審查方式**：文件檢閱：工作復健訓練紀錄、轉銜服務紀錄

- **配分**：4 分

**評鑑基準：**

1. 依據2.1「職業功能」評估結果及個人需求，提供適切、階段性之工作復健訓練及轉銜服務，並有紀錄
2. 提供多樣選擇之工作訓練內容

### 217. 2.7 定期生活諮詢及心理輔導

- **負責職務**：專業人員
- **審查方式**：文件檢閱：會談紀錄；現場訪談：學員

- **配分**：3 分

**評鑑基準：**

1. 主責專業人員應考量學員個別復健需求，每月至少1次，與學員會談並有紀錄
2. 會談紀錄應包含具體目的、輔導內容與後續處理計畫

### 218. 2.8 輔導規則就醫及藥物自我管理

- **負責職務**：專業人員
- **審查方式**：文件檢閱：藥物管理紀錄；現場訪談：學員（PFM）

- **配分**：2 分

**評鑑基準：**

1. 學員藥物應有清楚標示個案姓名、服用時間及劑量並有使用醫囑，且應有適當存放空間
2. 60%以上的學員可自行保管全部藥物
3. 對於服藥遵從性需要改善的學員，應輔導協助就醫，評估是否調整藥物或使用長效針劑
4. 應有輔導規則就醫及藥物自我管理訓練計畫，並落實執行

### 219. 2.9 召開社區復健及適應討論會

- **負責職務**：專業人員
- **審查方式**：文件檢閱：討論會紀錄；現場訪談：學員

- **配分**：2 分

**評鑑基準：**

1. 學員每人至少每月參加1次，每次至少需達45分鐘
2. 團體人數不超過30人，若學員超過30人，則分團體進行
3. 依學員實際適應情況產生議題
4. 紀錄完整

### 220. 2.10 召開學員自治會議

- **負責職務**：社工/專業人員
- **審查方式**：文件檢閱：自治會議紀錄；現場訪談：學員

- **配分**：2 分

**評鑑基準：**

1. 由學員擔任主席及記錄
2. 每人每月至少參加1次，每次至少45分鐘以上
3. 團體人數不超過50人，若超過50人，則分團體進行
4. 工作人員列席並有指導學員學習會議運作
5. 紀錄有公告周知或傳閱

### 221. 2.11 提供學員家庭支持服務

- **負責職務**：社工
- **審查方式**：文件檢閱：家屬聯繫紀錄、家屬活動紀錄

- **配分**：2 分

**評鑑基準：**

1. 定期與家屬聯絡及討論學員復健情形，並備有紀錄
2. 至少每半年舉辦1次家屬座談會或聯誼活動，全年度累計共有50%以上學員之家屬參加，並有紀錄
3. 應採多元管道，鼓勵家屬參與學員復健活動，強化學員支持與關懷

### 222. 2.12 社區融合

- **負責職務**：專業人員
- **審查方式**：文件檢閱：社區融合活動紀錄；現場訪談：學員（PFM）

- **配分**：4 分

**評鑑基準：**

1. 機構應訂有年度計畫，至少每半年參與1次機構外之社區交流活動
2. 持續性參與社區服務
3. 每位學員均可參與社區融合活動

### 223. 2.13 社會參與

- **負責職務**：專業人員
- **審查方式**：文件檢閱：活動紀錄；現場訪談：學員

- **配分**：0 分

**評鑑基準：**

1. 機構有安排學員參與各種公民活動或倡議活動，增進與社會的連結及社會角色的建立
2. 學員可具體說出活動內容與頻率
3. 有各類活動紀錄及照片佐證

### 224. 2.14 同儕支持

- **負責職務**：專業人員
- **審查方式**：文件檢閱：活動紀錄；現場訪談：學員、工作人員

- **配分**：0 分

**評鑑基準：**

1. 機構有提供或促使學員自然形成社群的機會或場域，強化學員間的相互支持
2. 有活動紀錄及照片佐證

## 第3章、服務品質（3）

### 325. 3.1 訂有工作手冊，並落實執行

- **負責職務**：負責人
- **審查方式**：文件檢閱：工作手冊

- **配分**：2 分

**評鑑基準：**

1. 訂有適切的工作手冊，並落實執行，且每年檢討及修正

### 326. 3.2 訂定適當收案標準，並落實執行

- **負責職務**：負責人/專業人員
- **審查方式**：文件檢閱：收案標準、收案紀錄；現場訪談：學員（PFM）

- **配分**：3 分

**評鑑基準：**

1. 訂定適當收案標準且落實執行
2. 訂有收案評估及檢討改善機制

### 327. 3.3 訂定適當結案標準，並落實執行

- **負責職務**：負責人/專業人員
- **審查方式**：文件檢閱：結案標準、結案紀錄、回歸社區生活紀錄

- **配分**：3 分

**評鑑基準：**

1. 依據結案標準確實執行學員回歸社區生活計畫，並備有結案紀錄及通報學員住（居）所在地衛生局
2. 4年內有15%以上學員功能進步，結案回歸社區生活
3. 並有實際經復健後功能進步、結案回歸社區生活且為家屬接受，有就學、就業成功案例

### 328. 3.4 紀錄完整，並妥善管理

- **負責職務**：負責人/專業人員
- **審查方式**：文件檢閱：個案紀錄、紀錄管理辦法

- **配分**：4 分

**評鑑基準：**

1. 紀錄應統整各專業之資料以呈現學員之復健情形
2. 訂有個案紀錄管理辦法，且落實執行
3. 具保密性措施

### 329. 3.5 適切的復健基金管理

- **負責職務**：負責人/行政人員
- **審查方式**：文件檢閱：復健基金管理要點、收支明細表、工作獎勵紀錄；現場訪談：學員（PFM）

- **配分**：3 分

**評鑑基準：**

1. 訂有復健基金管理要點，且成立管理委員會或小組，有學員代表參加
2. 復健基金全數運用於學員所需，其中90%應列為工作獎勵，並按月發放
3. 應有獨立的收支明細表並每月公告
4. 學員如擔任機構內之服務工作，應給予適當工作獎勵金，並備有清冊
5. 學員接受復健治療所衍生之收入須以現金方式給予，不得以點數方式兌換

### 330. 3.6 落實學員權益維護措施

- **負責職務**：負責人/社工
- **審查方式**：文件檢閱：權益維護相關文件、申訴處理流程；現場訪談：學員（PFM）；現場查看

- **配分**：3 分

**評鑑基準：**

1. 落實精神衛生法有關權益之相關規定
2. 機構應妥善管理學員個人資料，並應遵行精神復健機構個人資料檔案安全維護計畫實施辦法之規定
3. 訂有性騷擾防治辦法且確實教育及周知學員
4. 機構應依學員學習需求，提出維護及教育權益的具體方法、策略，並納入個別化服務計畫執行且有紀錄
5. 如需錄音或錄影需獲得學員同意，並有同意書
6. 學員相關權益或公約規範有以學員易懂之文字描述且張貼於明顯處，內容以書面告知學員並有簽名
7. 設施及設備應維護學員隱私
8. 訂有申訴處理流程（註明主管機關申訴電話）
9. 收費標準及項目均經主管機關核定

### 331. 3.7 落實學員健康維護措施

- **負責職務**：負責人/專業人員
- **審查方式**：文件檢閱：健康檢查紀錄、健康維護措施紀錄；現場查看

- **配分**：3 分

**評鑑基準：**

1. 收案時，應有基本健康檢查資料，且每年至少1次胸部X光檢查，並依全民健康保險成人健康檢查相關規範定期進行健康檢查
2. 針對健康檢查異常結果應進行追蹤處理
3. 參與例行性餐飲及食品製作之學員應同時依衛生福利部食品藥物管理署規範之檢查項目進行健康檢查
4. 學員之杯子、碗筷等個人物品應有防止共用或汙染之措施
5. 應配合政府照顧身心障礙者口腔衛生政策，並具鼓勵學員每半年接受口腔健康檢查之措施
6. 有充足且適當之洗手設施和洗手用品
7. 機構應提供健康維護措施等相關宣導資料，定期施行實體課程，並有紀錄備查
8. 宣導及鼓勵學員配合國家政策，接種各類疫苗並掌握其疫苗接種或免疫力情形
9. 訂有學員健康監測機制，且有紀錄，並定期分析檢討（至少每半年），及依「人口密集機構傳染病監視作業注意事項」規定執行疫情監測及上網登錄通報

### 332. 3.8 訂定處理緊急醫療、異常及群聚感染事件處理流程，並落實執行

- **負責職務**：負責人/專業人員
- **審查方式**：文件檢閱：緊急事件處理流程、處理紀錄

- **配分**：2 分

**評鑑基準：**

1. 依據各類緊急醫療、異常事件、疑似感染個案及群聚感染事件之不同特性，訂定適切之處理作業流程，並落實執行
2. 所有工作人員應有基本急救訓練與感染管制教育訓練紀錄
3. 遇有緊急狀況，工作人員應協助學員儘速就醫，並做好個人防護，且有紀錄備查
4. 疑似感染個案及群聚感染事件處理流程至少包括通知相關人員或單位、安排照護之工作人員、使用防護裝備、與他人區隔、協助安排個案就醫、協助檢體採集、疑似感染區域（含動線）清潔消毒等，且有紀錄備查

### 333. 3.9 建立機構緊急應變管理機制並落實執行

- **負責職務**：負責人
- **審查方式**：文件檢閱：緊急應變計畫、演練紀錄、備查紀錄

- **配分**：2 分

**評鑑基準：**

1. 依據緊急災害應變措施及檢查辦法，對於火災、風災、水災、地震等緊急災害，訂有符合機構特性與危機管理的複合式緊急災害應變措施計畫及作業程序
2. 每半年至少辦理一次複合式緊急災害應變演練，並有紀錄備查
3. 每半年至少辦理一次自衛消防編組演練，並備有紀錄
4. 年度複合式緊急災害應變計畫相關成果通過衛生主管機關備查，年度自衛消防編組訓練計畫相關成果通過消防主管機關備查
5. 學員擅自離開該機構時，應即通知其家屬或保護人；學員行蹤不明時，應即通知地方主管機關及警察機關協尋

### 334. 3.10 召開品質管理相關會議

- **負責職務**：負責人/品質管理負責人
- **審查方式**：文件檢閱：品質管理會議紀錄

- **配分**：2 分

**評鑑基準：**

1. 每月定期召開1次，紀錄內容完整，且有追蹤及檢討改善措施
2. 專業人員（含兼任人員）有參與品質管理相關會議

### 335. 3.11 執行學員及家屬滿意度調查

- **負責職務**：負責人/社工
- **審查方式**：文件檢閱：滿意度調查表、統計分析報告、改善紀錄

- **配分**：2 分

**評鑑基準：**

1. 每年至少進行1次學員及家屬滿意度調查，且有統計分析並將結果周知學員
2. 有後續處理措施及紀錄

### 336. 3.12 訂定並落實訪客管理規範，且有訪客紀錄

- **配分**：0 分

3. 能依據不同疫情（機構發生疫情或政府發布疫情警示等）訂定規範
