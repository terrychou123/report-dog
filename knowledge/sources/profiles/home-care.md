# 居家服務機構 評鑑基準

> 115年度臺北市政府社會局居家服務機構評鑑基準

## 壹、個案權益保障（權）

### 權1. 服務資訊公開

- **負責職務**：行政/社工
- **審查方式**：文件檢閱、現場訪談


**評鑑基準：**

1. 製作機構簡介或文宣，且內容完整（含服務項目、收費標準、服務時間、服務區域）
2. 隨時更新簡介或文宣與相關服務訊息
3. 設有機構公開的網路平台介紹居家服務內容
4. 設有其他宣傳方式（如社區公告欄、媒體報導、合作單位轉介資訊）

### 權2. 個案基本權益維護

- **負責職務**：社工/照服員
- **審查方式**：文件檢閱、現場訪談、個案訪視


**評鑑基準：**

1. 訂有個案權益保障相關規定或聲明書
2. 入案時向個案及家屬說明權益保障內容並簽署
3. 工作人員熟知並落實個案權益保障規定
4. 無歧視、虐待、剝削個案之情事

### 權3. 個案隱私保護

- **負責職務**：全體人員
- **審查方式**：文件檢閱、現場訪視


**評鑑基準：**

1. 訂有個案隱私保護相關規定
2. 個案資料妥善保存，非相關人員不得任意調閱
3. 服務人員入戶服務時遵守個案隱私保護規定
4. 照片、影音等資料蒐集使用符合個人資料保護法規定

### 權4. 申訴機制

- **負責職務**：行政/社工
- **審查方式**：文件檢閱、訪談


**評鑑基準：**

1. 訂有個案申訴處理程序
2. 設有申訴管道（如申訴信箱、電話、書面），且個案及家屬知悉
3. 申訴案件有書面記錄及追蹤處理
4. 申訴處理結果回覆申訴人

## 貳、專業照護品質（專）

### 專5. 入案評估

- **負責職務**：社工/照服員
- **審查方式**：文件檢閱、個案紀錄查閱


**評鑑基準：**

1. 入案前完成居家需求評估，含身體功能、日常生活能力、居家環境等面向
2. 評估工具標準化（如 ADL、IADL 等）
3. 評估結果有書面記錄且由專業人員簽名
4. 定期（至少每年）重新評估並更新紀錄

### 專6. 個別服務計畫

- **負責職務**：社工
- **審查方式**：文件檢閱、訪談


**評鑑基準：**

1. 依評估結果為每位個案擬定個別服務計畫
2. 計畫包含服務目標、服務項目、頻率、負責人員
3. 計畫已告知個案及家屬並獲同意簽署
4. 計畫定期（至少每半年）檢視更新

### 專7. 服務計畫執行與評值

- **負責職務**：照服員/社工
- **審查方式**：文件檢閱、個案紀錄查閱


**評鑑基準：**

1. 服務計畫按時執行並有服務紀錄
2. 定期（至少每半年）評值計畫執行成效
3. 依評值結果調整服務計畫
4. 計畫變更有書面記錄並通知個案及家屬

### 專8. 身體照顧服務

- **負責職務**：照服員
- **審查方式**：文件檢閱、個案訪視、訪談


**評鑑基準：**

1. 提供協助盥洗、如廁、穿脫衣物等個人衛生照顧，符合個案需求
2. 依個案需求提供移位、翻身、步行協助等身體照護
3. 服務過程確保個案安全，預防跌倒及意外
4. 照服員以尊重、有耐心方式提供入戶照顧

### 專9. 日常生活協助

- **負責職務**：照服員
- **審查方式**：文件檢閱、個案紀錄查閱


**評鑑基準：**

1. 依個案服務計畫提供家務協助（備餐、洗衣、環境清潔等）
2. 服務內容與個案需求及計畫相符
3. 服務紀錄完整記載服務項目、時間、執行情形
4. 家務協助不超越服務範疇規定

### 專10. 緊急事件處理

- **負責職務**：全體人員
- **審查方式**：文件檢閱、訪談


**評鑑基準：**

1. 訂有居家服務緊急事件（跌倒、急症、個案失蹤等）處理標準作業程序
2. 緊急事件有書面通報、處理及追蹤記錄
3. 照服員熟知入戶服務時緊急事件處理流程及聯絡窗口
4. 定期辦理緊急事件教育訓練並有記錄

### 專11. 家屬溝通與參與

- **負責職務**：社工
- **審查方式**：文件檢閱、訪談


**評鑑基準：**

1. 定期（至少每半年）與個案或主要照顧者進行服務溝通
2. 有書面溝通記錄（電話、面談紀錄）
3. 家屬有機會參與服務計畫討論及調整
4. 家屬反映意見有書面處理記錄

### 專12. 督導與訪視

- **負責職務**：社工/督導
- **審查方式**：文件檢閱、訪談


**評鑑基準：**

1. 訂有居家服務督導制度及訪視頻率規定
2. 定期辦理電訪、入戶訪視並有書面記錄
3. 督導發現問題有追蹤改善記錄
4. 照服員能定期與督導反映服務執行狀況

### 專13. 服務紀錄

- **負責職務**：全體人員
- **審查方式**：文件檢閱、抽查個案紀錄


**評鑑基準：**

1. 服務紀錄格式統一且完整（含服務日期、時間、項目、執行情形）
2. 服務紀錄即時填寫，照服員親自填寫並簽名
3. 電子或書面紀錄保存符合規定年限
4. 異常服務狀況有特別記載及通報

### 專14. 結案與轉介

- **負責職務**：社工
- **審查方式**：文件檢閱


**評鑑基準：**

1. 訂有結案標準及程序
2. 結案時完成結案摘要並告知個案及家屬
3. 轉介其他服務（如機構式服務、醫療）時有書面轉介資料
4. 轉介後有追蹤確認個案後續安置情形

## 參、經營管理效能（管）

### 管15. 機構行政管理

- **負責職務**：主管
- **審查方式**：文件檢閱


**評鑑基準：**

1. 訂有機構組織章程及各項行政管理規定
2. 各項行政作業有標準作業程序
3. 行政文件分類管理，查閱方便
4. 定期召開行政會議並有記錄

### 管16. 人員配置

- **負責職務**：主管
- **審查方式**：文件檢閱、現場訪視


**評鑑基準：**

1. 依法令規定配置照服員及督導人員
2. 排班合理，服務時段符合個案需求
3. 照服員與個案比例符合規定
4. 人員缺額有即時補充機制

### 管17. 人員資格

- **負責職務**：主管/行政
- **審查方式**：文件檢閱


**評鑑基準：**

1. 照服員具備法令規定之訓練資格（照顧服務員訓練結業證明）
2. 資格證書影本建檔保存
3. 督導人員具備相關專業資格
4. 新進人員資格審核有書面記錄

### 管18. 人員訓練

- **負責職務**：主管/社工
- **審查方式**：文件檢閱、訓練記錄查閱


**評鑑基準：**

1. 訂有年度教育訓練計畫
2. 新進照服員有職前訓練並有記錄（含服務規範、安全守則、緊急處置）
3. 全體人員每年至少完成規定時數之在職訓練
4. 訓練內容符合居家服務實際照護需求

### 管19. 人員健康管理

- **負責職務**：主管/行政
- **審查方式**：文件檢閱


**評鑑基準：**

1. 新進人員入職前完成健康檢查並有記錄
2. 定期（至少每年）辦理在職人員健康檢查
3. 患有傳染病之人員依規定停止入戶服務
4. 人員健康管理資料妥善保存

### 管20. 人員績效管理

- **負責職務**：主管
- **審查方式**：文件檢閱


**評鑑基準：**

1. 訂有人員考核制度及評核標準
2. 定期（至少每年）辦理人員考核
3. 考核結果有書面記錄並告知人員
4. 依考核結果提供適當獎懲或改善輔導

### 管21. 財務管理

- **負責職務**：主管/會計
- **審查方式**：文件檢閱


**評鑑基準：**

1. 財務收支有完整帳冊記錄
2. 收支憑證妥善保存
3. 定期辦理財務報表並公開（適用時）
4. 財務管理符合相關法規規定

### 管22. 收退費管理

- **負責職務**：行政
- **審查方式**：文件檢閱、訪談


**評鑑基準：**

1. 收費標準公開且符合政府規定
2. 開立收費收據給付費者
3. 訂有退費規定並告知個案及家屬
4. 收退費爭議有書面處理記錄

### 管23. 專任服務人員年度留任率

- **負責職務**：主管
- **審查方式**：文件檢閱


**評鑑基準：**

1. 統計年度專任照服員留任率並有書面記錄
2. 留任率達機構訂定目標值
3. 針對離職原因進行分析並訂定改善措施
4. 改善措施執行後有追蹤成效記錄

### 管24. 23-1 兼任服務人員年度留任率

- **負責職務**：主管
- **審查方式**：文件檢閱


**評鑑基準：**

1. 統計年度兼任照服員留任率並有書面記錄
2. 留任率達機構訂定目標值
3. 針對兼任人員離職原因進行分析並訂定改善措施
4. 改善措施執行後有追蹤成效記錄

### 管25. 資訊管理

- **負責職務**：行政
- **審查方式**：文件檢閱、系統查核


**評鑑基準：**

1. 個案資訊系統完整且資料即時更新
2. 資訊系統有權限管控，防止未授權存取
3. 資料定期備份
4. 配合政府資訊申報要求即時申報

### 管26. 感染管制

- **負責職務**：全體人員
- **審查方式**：文件檢閱、現場查核


**評鑑基準：**

1. 訂有感染管制計畫及入戶服務標準作業程序
2. 照服員入戶服務落實手部衛生及個人防護
3. 感染事件有通報及處理記錄
4. 定期辦理感染管制教育訓練

### 管27. 服務品質改善

- **負責職務**：主管/社工
- **審查方式**：文件檢閱、訪談


**評鑑基準：**

1. 定期進行服務品質自我評核
2. 依評核結果訂定改善計畫並執行
3. 品質改善成效有追蹤記錄
4. 服務品質問題有根本原因分析

### 管28. 服務使用者滿意度調查

- **負責職務**：社工
- **審查方式**：文件檢閱


**評鑑基準：**

1. 每年至少辦理一次個案及家屬滿意度調查
2. 調查工具有效且兼顧匿名性
3. 調查結果有書面分析報告
4. 依調查結果訂定改善措施並追蹤

### 管29. 品質監測機制

- **負責職務**：主管/社工
- **審查方式**：文件檢閱


**評鑑基準：**

1. 設有品質指標監測系統（如服務準時率、個案滿意度、申訴率）
2. 定期彙整品質指標數據並分析
3. 品質問題有改善行動計畫
4. 品質監測結果向上級或委員會報告

### 管30. 機構自評

- **負責職務**：主管
- **審查方式**：文件檢閱


**評鑑基準：**

1. 定期辦理機構自我評鑑
2. 自評結果有書面報告
3. 自評發現問題有改善計畫
4. 自評結果知會董事會或主管機關（適用時）

## 加分題（加）

### 加31. 創新服務或社區資源連結

- **負責職務**：主管/社工
- **審查方式**：文件檢閱、訪談


**評鑑基準：**

1. 推動創新服務模式或建立社區資源連結網絡
2. 有具體成果記錄（如合作方案、聯結資源清單、服務成效）
3. 創新服務或資源連結惠及個案及家屬
4. 有推廣分享或複製擴散之機制

### 加32. 照顧者支持服務

- **負責職務**：社工
- **審查方式**：文件檢閱、訪談


**評鑑基準：**

1. 提供家庭照顧者喘息、諮詢或教育支持服務
2. 辦理照顧者支持課程或團體並有記錄
3. 照顧者支持服務有成效追蹤
4. 有與其他單位合作提供照顧者支持之機制
