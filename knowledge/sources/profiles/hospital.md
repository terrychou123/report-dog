# 醫院評鑑 評鑑基準

> 114 年度衛生福利部醫院評鑑基準（區域醫院、地區醫院適用）

## 1.1 醫院經營策略（1.1）

### 1.11. 院務發展計畫

- **負責職務**：院長/管理層
- **審查方式**：資料查核＋訪談

- **類別**：一般
- **條文**：1.1.1

**評鑑基準：**

1. 醫院訂有院務發展計畫，內容包含使命、願景及中長期目標
2. 院務發展計畫經院方最高決策單位核定，並定期檢視執行成效
3. 院務發展計畫與醫院資源配置相互呼應，具可行性
4. 計畫執行成果定期向管理層或董事會報告

### 1.12. 組織架構與職掌

- **負責職務**：院長/各部門主管
- **審查方式**：資料查核

- **類別**：一般
- **條文**：1.1.2

**評鑑基準：**

1. 醫院訂有組織規程，明確規範各部門職掌與指揮系統
2. 組織圖公告周知，各部門職掌有書面規定
3. 各部門主管職務代理制度明確，不因人員異動影響業務執行

### 1.13. 品質管理組織與機制

- **負責職務**：品質管理部門/委員會
- **審查方式**：資料查核＋訪談

- **類別**：重點
- **條文**：1.1.3

**評鑑基準：**

1. 醫院設有品質管理委員會或相應組織，定期召開會議並有記錄
2. 品質管理計畫涵蓋全院各部門，有年度計畫及執行追蹤
3. 品質改善成效定期評估，並回饋各部門作為改善依據
4. 品質指標選定具臨床意義，監測頻率適當

### 1.14. 績效評估與管理

- **負責職務**：院長/管理層
- **審查方式**：資料查核

- **類別**：一般
- **條文**：1.1.4

**評鑑基準：**

1. 醫院建有績效評估制度，定期執行各部門及個人績效考核
2. 績效評估結果與獎懲、薪資調整或發展計畫連結
3. 績效考核過程公正客觀，員工有申訴管道

### 1.15. 社會責任與社區健康

- **負責職務**：院長/社區健康部門
- **審查方式**：資料查核＋訪談

- **類別**：一般
- **條文**：1.1.5

**評鑑基準：**

1. 醫院訂有社會責任政策，積極參與社區健康促進活動
2. 定期辦理社區衛教或免費篩檢等公益服務，並有執行紀錄
3. 配合政府政策推動預防保健及健康促進業務

## 1.2 員工管理與支持制度（1.2）

### 1.26. 員工支持方案

- **負責職務**：人力資源部門
- **審查方式**：資料查核＋訪談

- **類別**：一般
- **條文**：1.2.1

**評鑑基準：**

1. 醫院訂有員工協助方案（EAP），提供心理輔導、壓力疏導等支持資源
2. 員工遭遇職場暴力、性騷擾等事件有明確處理流程，並確實執行
3. 員工支持資源公告周知，員工知悉可運用之管道

### 1.27. 員工申訴機制

- **負責職務**：人力資源部門/管理層
- **審查方式**：資料查核＋訪談

- **類別**：一般
- **條文**：1.2.2

**評鑑基準：**

1. 醫院設有員工申訴管道，申訴案件均有紀錄、處理及追蹤
2. 申訴處理結果通知申訴人，申訴人不得遭受不當對待
3. 申訴制度定期宣導，員工實際知悉申訴流程

### 1.28. 職業安全衛生管理

- **負責職務**：職業安全衛生管理人員
- **審查方式**：資料查核＋實地查核

- **類別**：重點
- **條文**：1.2.3

**評鑑基準：**

1. 醫院依職業安全衛生法設置職安管理人員，訂有職安衛管理計畫
2. 定期辦理職場危害識別與風險評估，並採取適當控制措施
3. 職安事故有通報、調查及改善流程，並有紀錄
4. 工作人員接受職安教育訓練，有訓練紀錄

### 1.29. 職業傷害保護

- **負責職務**：人力資源部門/職安管理員
- **審查方式**：資料查核

- **類別**：一般
- **條文**：1.2.4

**評鑑基準：**

1. 醫院依規定為員工投保職業傷害保險，並辦理相關補償
2. 職業傷害（含針扎、血液暴露等）有標準處理流程，員工熟知
3. 職業傷害後追蹤管理完整，有書面紀錄

### 1.210. 員工健康管理

- **負責職務**：員工健康服務中心/人力資源部門
- **審查方式**：資料查核

- **類別**：一般
- **條文**：1.2.5

**評鑑基準：**

1. 新進員工依規定完成健康檢查，具傳染性疾病者依規定處理
2. 在職員工定期辦理健康檢查，結果有紀錄並依需要辦理工作調整
3. 醫院提供員工健康促進方案，有執行記錄

### 1.211. 勞動條件保障

- **負責職務**：人力資源部門
- **審查方式**：資料查核

- **類別**：一般
- **條文**：1.2.6

**評鑑基準：**

1. 醫院依勞動基準法及相關法規保障員工薪資、工時、休假等基本勞動權益
2. 工作時間符合規定，不違法要求員工超時工作
3. 員工薪資按時足額發放，無違規情事

### 1.212. 員工服務守則與倫理規範

- **負責職務**：院長/各部門主管
- **審查方式**：資料查核

- **類別**：一般
- **條文**：1.2.7

**評鑑基準：**

1. 醫院訂有員工服務守則及職業倫理規範，並確保員工知悉
2. 員工違反服務守則或倫理規範有明確懲處程序
3. 定期辦理倫理教育訓練，有訓練紀錄

## 1.3 人力資源管理（1.3）

### 1.313. 醫師人力配置

- **負責職務**：醫務部門/院長
- **審查方式**：資料查核

- **類別**：必要
- **條文**：1.3.1

**評鑑基準：**

1. 醫院各科別醫師人力符合醫療法及相關法規規定
2. 醫師執業執照有效，並完成執業登記
3. 醫師排班符合值班規定，保障病人安全

### 1.314. 護理人力配置

- **負責職務**：護理部門
- **審查方式**：資料查核＋實地查核

- **類別**：必要
- **條文**：1.3.2

**評鑑基準：**

1. 護理人員配置符合護理人員法及醫院設置標準規定
2. 護理人員執照有效，並完成執業登記
3. 病房護病比符合法規規定，有夜班護理人員值班
4. 護理人力不足時有緊急補足機制

### 1.315. 醫事人員配置

- **負責職務**：各醫事部門主管
- **審查方式**：資料查核

- **類別**：必要
- **條文**：1.3.3

**評鑑基準：**

1. 藥師、放射師、醫事檢驗師、物理治療師、職能治療師等醫事人員配置符合規定
2. 各類醫事人員執照有效，執業登記完整
3. 各部門人員配置滿足業務需求，不超出法定範圍

### 1.316. 社工及行政人力配置

- **負責職務**：社工部門/行政部門
- **審查方式**：資料查核

- **類別**：一般
- **條文**：1.3.4

**評鑑基準：**

1. 社工人力配置符合規定，社工師執照有效
2. 行政人員配置滿足醫院運作需求
3. 各部門人員職責明確，有書面工作說明

### 1.317. 新進人員職前訓練

- **負責職務**：教育訓練部門
- **審查方式**：資料查核

- **類別**：重點
- **條文**：1.3.5

**評鑑基準：**

1. 醫院訂有新進人員職前訓練計畫，涵蓋醫院政策、病人安全、感染管制等核心主題
2. 新進人員均完成職前訓練，訓練紀錄完整
3. 訓練效果評估有書面紀錄

### 1.318. 在職教育訓練

- **負責職務**：教育訓練部門/各科部
- **審查方式**：資料查核

- **類別**：重點
- **條文**：1.3.6

**評鑑基準：**

1. 醫院訂有年度在職教育訓練計畫，涵蓋各類職別
2. 各職類員工依規定完成每年應接受之訓練時數
3. 訓練紀錄完整，可供查核
4. 訓練成效定期評估，作為計畫修訂依據

### 1.319. 醫師繼續教育

- **負責職務**：醫務部門/各科主任
- **審查方式**：資料查核

- **類別**：一般
- **條文**：1.3.7

**評鑑基準：**

1. 醫師依規定完成繼續教育學分，有繼續教育紀錄
2. 醫院鼓勵並支持醫師參與學術研討及訓練
3. 住院醫師訓練計畫（如適用）符合衛生主管機關規定

### 1.320. 護理人員繼續教育

- **負責職務**：護理部門
- **審查方式**：資料查核

- **類別**：一般
- **條文**：1.3.8

**評鑑基準：**

1. 護理人員依規定完成繼續教育學分，有繼續教育紀錄
2. 醫院提供護理人員進修機會，支持職涯發展

### 1.321. 志願服務管理

- **負責職務**：社工部門/志工管理單位
- **審查方式**：資料查核

- **類別**：一般
- **條文**：1.3.9

**評鑑基準：**

1. 醫院設有志工管理制度，訓練、督導及考核機制完善
2. 志工執行服務前完成基本訓練，訓練紀錄完整
3. 志工服務範圍明確規定，不替代醫療專業人員作業

### 1.322. 人員資格審查與管理

- **負責職務**：人力資源部門
- **審查方式**：資料查核

- **類別**：一般
- **條文**：1.3.10

**評鑑基準：**

1. 醫院建立人員資格審查制度，確認各類人員之執照、證書有效
2. 人員進用時完成背景查核（含性侵害、兒少虐待等前科查詢）
3. 人員資格文件定期更新，有管理機制

## 1.4 病歷、資訊與溝通管理（1.4）

### 1.423. 病歷書寫與管理

- **負責職務**：醫務部門/病歷室
- **審查方式**：資料查核＋訪談

- **類別**：必要
- **條文**：1.4.1

**評鑑基準：**

1. 病歷書寫規範明確，醫療人員依規定書寫並簽名
2. 病歷保存符合規定，保存年限及管理程序完整
3. 病歷調閱有管理規定，未授權人員不得查閱
4. 電子病歷系統（如採用）符合相關法規及資安規定

### 1.424. 資訊安全管理

- **負責職務**：資訊部門
- **審查方式**：資料查核

- **類別**：重點
- **條文**：1.4.2

**評鑑基準：**

1. 醫院訂有資訊安全政策，明確規範資訊存取、保護及使用
2. 重要資料定期備份，有備份還原測試紀錄
3. 醫療資訊系統有存取管控機制，人員依權限使用
4. 發生資安事件時有通報及應變程序

### 1.425. 醫療資訊系統管理

- **負責職務**：資訊部門
- **審查方式**：資料查核

- **類別**：一般
- **條文**：1.4.3

**評鑑基準：**

1. 醫療資訊系統穩定運作，有定期維護及升級計畫
2. 系統故障時有緊急應變程序，確保業務持續運作
3. 系統資料完整性定期查核

### 1.426. 內外部溝通機制

- **負責職務**：各部門主管/行政部門
- **審查方式**：資料查核＋訪談

- **類別**：一般
- **條文**：1.4.4

**評鑑基準：**

1. 醫院建立有效之內部溝通機制，包含院務會議、部門會議等
2. 對外溝通管道暢通，病人及家屬可獲得及時、正確之醫療資訊
3. 緊急事件對外溝通有明確程序及授權規定

## 1.5 安全的環境與設備（1.5）

### 1.527. 建築物安全管理

- **負責職務**：設施管理部門
- **審查方式**：資料查核＋實地查核

- **類別**：重點
- **條文**：1.5.1

**評鑑基準：**

1. 醫院建築物符合建築、消防等相關法規，持有合法使用執照
2. 建築物定期維護檢查，有維護紀錄
3. 無障礙設施完善，符合相關法規規定
4. 電力、給排水系統定期維護，有緊急備用電源

### 1.528. 消防安全管理

- **負責職務**：設施管理部門/消防安全人員
- **審查方式**：資料查核＋實地查核

- **類別**：必要
- **條文**：1.5.2

**評鑑基準：**

1. 消防安全設備完善，定期檢查維護並有紀錄
2. 每年至少辦理 2 次消防疏散演練（含夜間演練），有演練紀錄
3. 全體員工熟知消防逃生路線及緊急應變程序
4. 病人疏散計畫明確，含臥床、行動不便病人之疏散方式

### 1.529. 醫療設備管理

- **負責職務**：醫療設備部門
- **審查方式**：資料查核＋實地查核

- **類別**：重點
- **條文**：1.5.3

**評鑑基準：**

1. 醫療設備有清冊，定期預防性維護並有紀錄
2. 設備故障有通報及維修流程，不影響病人安全
3. 高風險設備（如呼吸器、電刀等）使用前有安全查核
4. 設備使用人員接受相關訓練，有訓練紀錄

### 1.530. 危險物品管理

- **負責職務**：安全管理部門/各相關部門
- **審查方式**：資料查核＋實地查核

- **類別**：重點
- **條文**：1.5.4

**評鑑基準：**

1. 醫院訂有危險物品（化學品、放射性物質、壓縮氣體等）管理規定
2. 危險物品有清冊，儲存符合規定，標示清楚
3. 危險物品洩漏或意外有緊急應變程序，人員熟知
4. 操作危險物品之人員有適當防護裝備及訓練

### 1.531. 緊急應變計畫

- **負責職務**：緊急應變小組
- **審查方式**：資料查核

- **類別**：重點
- **條文**：1.5.5

**評鑑基準：**

1. 醫院訂有全面性緊急應變計畫，涵蓋各類災害情境
2. 緊急應變計畫定期演練，有演練紀錄及改善追蹤
3. 緊急應變指揮系統明確，人員職責清楚
4. 與外部緊急救護體系有聯繫機制

### 1.532. 環境清潔管理

- **負責職務**：感染管制部門/環境清潔管理
- **審查方式**：資料查核＋實地查核

- **類別**：一般
- **條文**：1.5.6

**評鑑基準：**

1. 環境清潔管理制度完善，各區域清潔頻率及方法有規定
2. 清潔人員接受感染管制相關訓練，有訓練紀錄
3. 環境清潔稽核定期執行，有稽核紀錄及改善追蹤

### 1.533. 廢棄物管理

- **負責職務**：環境安全部門
- **審查方式**：資料查核＋實地查核

- **類別**：重點
- **條文**：1.5.7

**評鑑基準：**

1. 醫療廢棄物分類、標示、儲存、清除及處理符合法規規定
2. 一般廢棄物及醫療廢棄物分開處理，不得混用
3. 廢棄物處理委外時，委外廠商資格合格，有委託契約及轉運聯單
4. 廢棄物管理相關人員接受訓練，有訓練紀錄

## 2.1 病人及家屬權責（2.1）

- **條文**：2.1.2

### 2.145. 病人隱私保護

- **類別**：必要
- **條文**：2.1.3

**評鑑基準：**

1. 病人個人資料依個人資料保護法規定保護，未授權不得外洩
2. 執行診察、護理操作時注重病人身體隱私
3. 病人紀錄及健康資訊僅供有需要之醫療人員查閱

### 2.146. 病人申訴機制

- **負責職務**：品質管理部門
- **審查方式**：資料查核

- **類別**：重點

1. 每位住院病人有個別化照護計畫，由跨專業團隊共同擬定

2. 電子處方簽核流程完整，防止未授權存取

- **負責職務**：藥師
- **審查方式**：資料查核＋實地查核

**評鑑基準：**

1. 藥品調劑由藥師執行，有調劑查核機制

## 2.7 感染管制（2.7）

### 2.7108. 感染管制組織與運作

- **負責職務**：感染管制委員會/感染管制醫師
- **審查方式**：資料查核

- **類別**：必要
- **條文**：2.7.1

**評鑑基準：**

1. 醫院設有感染管制委員會，定期召開會議，有紀錄
2. 感染管制醫師及護理師人力符合規定
3. 感染管制計畫完整，年度計畫執行有追蹤報告

### 2.7109. 標準防護措施與接觸隔離

- **負責職務**：全體醫療人員
- **審查方式**：資料查核＋訪談＋實地查核

- **類別**：必要
- **條文**：2.7.2

**評鑑基準：**

1. 手部衛生（手部清潔時機及方法）訓練落實，稽核執行率達標
2. 接觸隔離、飛沫隔離及空氣隔離措施執行正確
3. 個人防護裝備（PPE）使用正確，有訓練紀錄
4. 針頭及銳器使用安全，有安全針具設備

### 2.7110. 醫療照護相關感染監測

- **負責職務**：感染管制護理師/感染管制醫師
- **審查方式**：資料查核

- **類別**：必要
- **條文**：2.7.3

**評鑑基準：**

1. 醫療照護相關感染（如中央靜脈導管感染、呼吸器相關肺炎等）定期監測
2. 感染率計算方法標準化，與同類醫院比較
3. 感染率異常時有即時調查及改善措施
