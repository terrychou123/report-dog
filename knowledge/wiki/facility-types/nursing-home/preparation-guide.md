# 住宿型照顧機構評鑑準備完整指南

> 114 年度臺北市老人安養暨長期照顧機構評鑑，共 75 項正式指標（含加分與扣分項目）。

## 準備時程建議

### 評鑑前 3 個月

- [ ] 取出前次評鑑報告，建立改善追蹤表，改善率需達 80% 以上（管73）
- [ ] 盤點護理人員、照服員人數是否符合設置標準，日夜班分開計算（管9、管11）
- [ ] 確認業務負責人（主任/院長）已在機構投保勞健保、提撥勞退金（管7）
- [ ] 確認近 4 年查核缺失（消防、衛福、建管、勞工）逐項改善並備有佐證（管4）
- [ ] 更新感染管制手冊至當年度，確認防疫 SOP 完整（專25）
- [ ] 啟動各類品質監測季度分析：跌倒（專28）、壓傷（專29）、感染（專32）、體重（專34）

### 評鑑前 1 個月

- [ ] 確認每位工作人員年度在職訓練達 20 小時，感染管制至少 4 小時（管14）
- [ ] 確認新進工作人員職前訓練已於到職 1 個月內完成（至少 16 小時）（管13）
- [ ] 抽查廚工丙級餐飲技術士執照正本，確認已接受 8 小時外部衛生訓練（管15）
- [ ] 確認管制藥品已上鎖儲存，不再使用的管制藥品備有回收銷毀記錄（專26）
- [ ] 確認約束個案同意書在 3 個月有效期內，監測記錄完整（專31）
- [ ] 確認消防設備半年定期檢修記錄已向消防機關申報備查（管56）
- [ ] 確認每年已辦理 2 次緊急災害應變演練（含夜間及複合型），並有照片及檢討記錄（管58）

### 評鑑前 1 週

- [ ] 抽查 5 份個案完整紀錄（入住評估 → 照顧計畫 → 執行紀錄 → 醫師巡診）
- [ ] 確認新入住住民在 72 小時內完成個別化評估（含跌倒、壓傷、營養三大高風險）（專17）
- [ ] 現場測試所有緊急呼叫設備，浴室關門狀態下按鈴，確認工作人員即時反應（管51）
- [ ] 確認廚房食物檢體留存符合規定（每樣 150 公克、冷藏 48 小時）（管54）
- [ ] 確認水塔清潔保養記錄及水質檢驗報告在效期內（管63）
- [ ] 清查儲藏室易燃物品是否密閉上鎖，走道、防火門周圍 1.5 公尺淨空（管57）

### 評鑑當天

- [ ] 備齊所有文件依五大區塊分類擺放（管理效能 A / 專業照護 B / 安全環境 C / 個案權益 D / 創新）
- [ ] 提醒護理人員備妥侵入性照護 SOP（抽痰、換藥、換管路），可能被現場抽測（專38）
- [ ] 確認護理站急救設備完整、氧氣鋼瓶在效期內（管62）
- [ ] 提醒照服員確認翻身拍背記錄時間與實際操作一致，不得有空白頁（專42）
- [ ] 確認每間寢室洗手液或乾洗手液在效期內（專25）

## 優先準備項目

以下標記為 ⚠️ 的指標為最容易被扣分的高風險項目：

### 經營管理效能（管）

| 指標 | 警告重點 |
|------|---------|
| ⚠️ 管2 入出機構管理 | 現場實際服務人數不得超過許可床數，收案類型需與立案相符；建議主動索取近 4 年無違規收容的書面確認 |
| ⚠️ 管4 缺失改善 | 查核對象含衛福、消防、建管、勞工，需建立逐項改善追蹤表，改善率 100% 才達標 |
| ⚠️ 管5 住民保護機制 | 住民保護、性騷擾、性侵害需分別訂定，各有獨立流程；若有外籍員工需備有母語版本 |
| ⚠️ 管7 業務負責人 | 主任/院長必須專任、確實在機構投保勞健保；委員通常現場訪談確認非掛名 |
| ⚠️ 管9 護理人員 | 一級必要項目；全日均需有護理人員上班（含夜班），執業登錄需有效 |
| ⚠️ 管11 照服員 | 一級必要項目；日夜班比例分開計算，外籍照服員不得超過本國籍照服員及護理人員總數 |

### 專業照護品質（專）

| 指標 | 警告重點 |
|------|---------|
| ⚠️ 專17 個案服務計畫 | 新入住 72 小時內完成個別化評估（跌倒、壓傷、營養），每 3 個月定期評估，計畫修正需有家屬參與記錄 |
| ⚠️ 專24 醫療服務 | 特約醫師巡診記錄不得以門診記錄代替；長照型每月巡診，安養型每 3 個月，新入住 1 個月內完成首次評估 |
| ⚠️ 專25 防疫機制 | 住民每日量體溫、工作人員每週至少量 1 次且記錄完整；每間寢室需有洗手設施且在效期內 |
| ⚠️ 專26 藥品管理 | 管制藥品需專設上鎖櫃；不再使用的管制藥品需送交健保特約藥局回收並有回收記錄 |
| ⚠️ 專29 壓力性損傷 | 每季定期分析（安養不適用）；評鑑委員可能現場查看住民皮膚狀況 |
| ⚠️ 專31 約束管理 | 需醫師診斷或護理人員專業判斷，同意書 3 個月有效期；委員現場查看有無不當約束 |
| ⚠️ 專32 感染監測 | 需涵蓋疥瘡、呼吸道、腸道、不明原因發燒；群聚感染通報記錄是重要查核文件 |
| ⚠️ 專38 侵入性照護 | 護理人員需能現場抽測操作技術（抽痰、換藥、換管路），且有定期稽核記錄 |
| ⚠️ 專41 下床活動 | 可移動住民每日至少下床 2 次；重度失能住民需有被動式肢體活動記錄 |
| ⚠️ 專42 翻身拍背 | 每 2 小時翻身，記錄時間需與實際操作相符；委員可能現場比對護理記錄 |
| ⚠️ 專47 管灌照護 | 灌食時住民上半身抬高 30–45 度並維持 1 小時；每日至少 1 次天然食材 |

### 安全環境設備（安）

| 指標 | 警告重點 |
|------|---------|
| ⚠️ 管49 儲藏管理 | 易燃物品儲藏需密閉上鎖，儲藏室內需有適用的消防設備，定期盤點有記錄 |
| ⚠️ 管51 緊急呼叫 | 一級必要項目；浴室、廁所、寢室均需設置，功能需正常，委員現場實測 |
| ⚠️ 管53 無障礙浴廁 | 出入口無高差、扶手適當、輪椅迴轉空間足夠、至少 2 處求助鈴 |
| ⚠️ 管54 廚房衛生 | 食物檢體每樣 150 公克、冷藏 48 小時；供膳外包需有 GHP 稽查或 HACCP 合格證明 |
| ⚠️ 管56 消防設備 | 一級必要項目；每半年委託消防設備師定期檢修，需向消防機關申報，備前 2 次完整記錄 |
| ⚠️ 管57 疏散避難 | 一級必要項目；防火門隨時關閉且不需鑰匙可雙向開啟，走道、出入口保持暢通 |
| ⚠️ 管58 緊急災害應變 | 一級必要項目；每年 2 次演練（含 1 次夜間），EOP 涵蓋火災、水災、地震、停電等 |
| ⚠️ 管59 疏散標示 | 各樓層張貼緊急避難平面圖（至少 A3），方向符合現場；委員可能抽測工作人員疏散操作能力 |
| ⚠️ 管62 護理站設備 | 一級必要項目；急救設備需完整（氧氣、甦醒袋、急救藥品），各項在效期內 |

### 個案權益保障（個）

| 指標 | 警告重點 |
|------|---------|
| ⚠️ 管65 服務契約 | 住民至少 5 天審閱期需書面記錄，契約不得低於定型化契約，不得含不得記載事項 |

## 常見錯誤

1. **照顧計畫套模板**：所有住民使用相同制式計畫，未反映 72 小時入住評估結果或每 3 個月評估修正結果（專17）
2. **巡診記錄缺漏**：以門診記錄代替巡診記錄，或新入住住民未在 1 個月內完成首次醫師評估（專24）
3. **管制藥品未上鎖**：藥品儲存空間沒有上鎖設備，或不再使用的管制藥品無回收記錄（專26）
4. **翻身記錄與現場不符**：護理記錄顯示每 2 小時翻身，但委員現場觀察或住民皮膚顯示未確實執行（專42）
5. **感染監測只記錄通報，無分析**：有感染事件記錄但缺少逐案分析及每半年的 SOP 檢討（專32）
6. **演練有做但無記錄**：緊急災害應變演練未留存演練過程照片及事後改善記錄（管58）
7. **約束同意書過期**：約束個案的家屬同意書超過 3 個月有效期未更新（專31）
8. **業務負責人掛名**：主任/院長未實際在機構投保勞健保，或無法說明品質管理具體措施（管7）
9. **品質監測只蒐集數據**：跌倒、壓傷等指標只有數據，缺少定期分析報告和改善行動計畫（專28、專29）
10. **缺失改善率未達標**：前次查核缺失未能 100% 改善，且無說明文件（管4）

## 評鑑當天注意

### 文件準備

- 依**五大區塊**分類擺放文件夾，建議用不同顏色區分：A 經營管理 / B 專業照護 / C 安全環境 / D 個案權益 / E 創新加分
- 個案抽查用的完整紀錄（入住評估 → 照顧計畫 → 巡診紀錄 → 護理執行記錄）準備至少 5 份
- 按時間排列會議記錄、訓練簽到表，方便委員快速核查

### 現場注意

- **護理站**：急救設備齊全，氧氣鋼瓶確認效期，急救藥品有效期明顯標示
- **走道暢通**：防火門隨時關閉，周圍 1.5 公尺淨空，無推車或物品堆放
- **寢室檢查**：每間設有洗手液且在效期內，床旁呼叫鈴功能正常，床與床之間有隔簾保護隱私
- **廚房備查**：當日食物檢體已留存，菜單與實際供餐一致

### 訪談準備

- **護理師**：需說明藥物管理流程（三讀五對）、侵入性照護 SOP、感染通報流程，並能示範翻身技術
- **照服員**：需了解所負責住民的照顧計畫重點，說明翻身、下床活動紀錄方式
- **社工**：需說明入出機構流程、跨專業聯繫機制、家屬電訪頻率及記錄方式
- **主任/院長**：需說明品質監測分析結果（跌倒、壓傷、感染）、緊急災害應變計畫執行情形、前次評鑑改善達成情況

### 加分機會（管74）

每項 0.5 分，最多加總 3 分，可事先整理佐證文件：
- 加入防災社區計畫
- 每年舉辦 4 次以上緊急災害應變演練
- 收治照護愛滋感染者
- 外籍照服員每年在職訓練達 6 小時以上（70% 以上達標）
- 協助緊急安置弱勢個案
