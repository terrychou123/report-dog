# 居家服務機構評鑑準備完整指南

> 115 年度臺北市政府社會局居家服務機構評鑑，共 30 項正式指標 + 2 項加分題。

## 準備時程建議

### 評鑑前 3 個月

- [ ] 啟動機構自評（管30），確保改善措施有足夠時間執行並留下追蹤記錄
- [ ] 盤點人力配置是否符合法令規定的照服員與個案比例（管16）
- [ ] 確認感染管制計畫已更新至當年度，SOP 含洗手步驟及個人防護裝備使用時機（管26）
- [ ] 啟動品質指標監測 PDCA 循環：服務準時率、個案滿意度、申訴件數/率（管29）
- [ ] 確認服務合約與入案說明書已列明收費標準及退費規定（管22）

### 評鑑前 1 個月

- [ ] 確認所有照服員照顧服務員訓練結業證書影本已建檔，效期即將到期者需有追蹤表（管17）
- [ ] 確認全體人員年度在職訓練時數達規定標準，新進人員有職前訓練記錄（管18）
- [ ] 確認每位照服員健康檢查記錄完整，傳染病人員停止入戶決定有書面授權（管19）
- [ ] 計算專任及兼任照服員留任率，分析離職原因並備具體改善措施（管23、管24）
- [ ] 辦理年度個案及家屬滿意度調查，完成書面分析報告並訂定改善措施（管28）

### 評鑑前 1 週

- [ ] 抽查 3–5 份個案的完整服務歷程紀錄（入案評估 → 個別服務計畫 → 執行紀錄 → 督導訪視）
- [ ] 確認申訴案件處理記錄表完整（即使無案件，每季仍需有查閱確認記錄）（權4）
- [ ] 確認個案權益聲明書清冊：每位個案入案時均已書面說明並簽署（權2）
- [ ] 確認網路平台（官網/LINE/FB）內容是最新的，連結有效（權1）
- [ ] 確認品質改善計畫表有完整 PDCA 記錄（管27）

### 評鑑當天

- [ ] 備齊所有文件依四大區塊（個案權益、專業照護、經營管理、加分題）分類擺放
- [ ] 確認資訊系統權限管控設定清單可供委員查閱（管25）
- [ ] 提醒照服員熟知緊急事件處理 SOP 及聯絡窗口（專10）
- [ ] 確認個別服務計畫均有個案或家屬親筆簽名（專6）
- [ ] 準備加分題具體成果資料：社區資源清單、照顧者課程簽到表（加31、加32）

## 優先準備項目

以下 10 個指標標記為 ⚠️ 警告，代表最容易被扣分的項目：

### 個案權益保障（權）

| 指標 | 警告重點 |
|------|---------|
| 權2 個案基本權益維護 | 個案權益聲明書需入案時當場說明並簽署，評鑑委員會抽查個案書面資料 |
| 權3 個案隱私保護 | 照片拍攝須另外取得書面授權，口頭同意不符合個人資料保護法規定 |

### 專業照護品質（專）

| 指標 | 警告重點 |
|------|---------|
| 專6 個別服務計畫 | 個案或家屬需親筆簽名同意，電子簽名須符合電子簽章法，否則需紙本備查 |
| 專9 日常生活協助 | 家務服務不得超越服務範疇（不包含全家人清潔、非個案使用空間），照服員須清楚邊界 |
| 專12 督導與訪視 | 電訪記錄不可過於簡略，需記載身體狀況、服務滿意度、近期特殊事項等至少三個面向 |

### 經營管理效能（管）

| 指標 | 警告重點 |
|------|---------|
| 管16 人員配置 | 人員缺額需有書面補充機制說明（委派單位、補足期限），不可只口頭稱「在招募中」 |
| 管17 人員資格 | 照顧服務員訓練結業證書影本必須建檔，外籍照服員資格認定需符合相關法規 |
| 管19 人員健康管理 | 健康檢查結果屬個人隱私，需有保密管理機制，傳染病人員停止入戶需書面授權記錄 |
| 管26 感染管制 | SOP 需包含洗手步驟、個人防護裝備使用時機、物品清消方式；疫情特別措施需另立記錄 |
| 管27 服務品質改善 | PDCA 循環需有完整四個步驟記錄，只有計畫（P）而無執行（D）和追蹤（C/A）是最常見缺失 |

## 常見錯誤

1. **申訴記錄空白**：無申訴案件不代表不需記錄，每季仍需有查閱確認的書面記錄（權4）
2. **入案未當場簽署**：個案權益聲明書只放在資料夾備查、未實際說明簽署（權2）
3. **照片未取書面授權**：以口頭同意取代書面授權，不符合個資法規定（權3）
4. **服務計畫缺個案簽名**：個別服務計畫僅由社工填寫，無個案或家屬親筆簽名（專6）
5. **家務超範疇**：照服員協助全家人清潔或非個案使用空間，超越長照服務規範（專9）
6. **督導記錄過簡**：電訪只記「狀況良好」，未記載三個以上面向（專12）
7. **PDCA 只做 P**：品質改善只有計畫書，缺乏執行記錄與追蹤成效（管27、管29）
8. **人員缺額無書面說明**：人力不足時僅口頭說明，未備招募機制書面佐證（管16）
9. **評值後計畫未調整**：定期評值後若未調整計畫，需書面記載維持不變的理由（專7）
10. **網站資訊過期**：機構網路平台顯示舊費用或已離職人員，與實際服務不符（權1）

## 評鑑當天注意

### 文件準備

- 依**四大區塊**分類擺放文件夾，每個區塊用不同顏色標示
- 抽查用個案完整紀錄（從入案評估到服務計畫到執行紀錄到督導訪視）準備 5 份備用
- 訓練簽到表、會議記錄依時間順序排列，方便委員快速翻閱
- 資訊系統帳號權限清單列印備用，供委員查閱管25

### 現場注意

- **入戶照護**：提醒照服員熟知緊急事件處理流程及聯絡窗口，評鑑當天可能進行訪談
- **隱私保護**：確認個案資料存放位置不讓非相關人員輕易取閱
- **感染管制**：個人防護裝備備品充足，洗手設備功能正常

### 訪談準備

- **照服員**：需熟知所負責個案的服務計畫重點、服務範疇界線，以及緊急事件通報對象
- **社工**：需能說明入案評估流程、督導訪視制度、結案/轉介程序
- **主管**：需說明品質指標改善措施、留任率分析、年度自評執行情形
- **行政**：需能說明資訊系統權限管控設定及定期備份機制
