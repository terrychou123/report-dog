# 日間照顧中心評鑑準備完整指南

> 115 年度臺北市政府社會局日間照顧機構評鑑，共 43 項正式指標 + 2 項加分題。

## 準備時程建議

### 評鑑前 3 個月

- [ ] 取出上次評鑑報告，建立 [改善追蹤表](./items/27-前次評鑑建議改善情形.md)（管27，115 年度新增）
- [ ] 盤點人力配置是否符合設置標準（管28）
- [ ] 確認感染管制手冊已更新至當年度（專21）
- [ ] 啟動品質指標 PDCA 季度分析（專22）
- [ ] 確認所有服務契約使用社會局核定版本（權3）

### 評鑑前 1 個月

- [ ] 檢查每位服務人員的健康檢查（管32）和疫苗接種記錄（管33）
- [ ] 確認急救箱物品在有效期限內，員工 CPR+AED 證照未過期（管36）
- [ ] 更新年度教育訓練記錄，確認每人達 20 小時（管29）
- [ ] 計算服務人員留任率，低於 60% 需備書面說明（管30）
- [ ] 確認性騷擾防治規定已公告且有訓練記錄（管37，115 年度新增）

### 評鑑前 1 週

- [ ] 抽查 3-5 份個案的完整服務歷程紀錄（權3 契約 → 權5 評估 → 專6 照顧計畫 → 專7 執行紀錄）
- [ ] 確認環境清潔紀錄表、病媒防治紀錄齊全（安43）
- [ ] 確認飲用水檢驗報告在效期內（安41）
- [ ] 確認廚房衛生查核表完整（安42）
- [ ] 現場走一遍：扶手穩固、地板防滑、走道暢通、照明充足（安38）

### 評鑑當天

- [ ] 備齊所有文件依區塊分類擺放
- [ ] 確認網站資訊與實際服務內容一致（權1）
- [ ] 提醒照服員展現促進個案自主的照護態度（專11）
- [ ] 確認器材功能正常（管26）
- [ ] 確認防疫物資庫存充足（專21）

## 常見錯誤

1. **申訴記錄空白**：「沒有申訴案件」不代表不需要記錄，每季仍需有查閱確認的書面記錄（權2）
2. **照顧計畫套模板**：所有個案使用相同制式 ICP，未反映個別評估結果（專6）
3. **藥物未上鎖**：藥物儲存空間沒有上鎖設備（專12）
4. **網站資訊過期**：機構網站顯示舊年度費用或已離職人員（權1）
5. **演練無記錄**：防疫演練或緊急事件演練有做但沒有書面記錄（專21、管35）
6. **評估與計畫脫鉤**：重新評估發現顯著變化但照顧計畫未相應調整（專5、專7）
7. **PDCA 只做 P**：品質指標只有數據蒐集（Plan），沒有分析（Check）及改善行動（Act）（專22）
8. **契約版本錯誤**：使用機構自製契約而非社會局核定版本（權3）

## 評鑑當天注意

### 文件準備

- 依**四大區塊**分類擺放文件夾，每個區塊用不同顏色標示
- 個案抽查用的完整紀錄（從評估到計畫到執行）準備 5 份備用
- 會議記錄、訓練簽到表依時間排列

### 現場注意

- **走道暢通**：淨寬 120cm 以上，無堆放物品
- **地板防滑**：特別注意浴室和走廊轉角
- **標示清楚**：方向標示需大字加圖示
- **器材正常**：輪椅煞車、助行器穩固、電動床功能

### 訪談準備

- 照服員需了解所負責個案的照顧計畫重點
- 社工需能說明服務流程及轉介機制
- 護理師需說明藥物管理及緊急處理 SOP
- 主任需說明品質指標改善措施及年度計畫執行情形
