# 醫院評鑑準備完整指南

> 114 年度衛生福利部醫院評鑑基準（區域醫院、地區醫院適用），共 124 項指標，涵蓋院務管理、病人權益、醫療照護品質與安全等面向。其中 **必要項目** 未達標將直接影響評鑑等級，務必優先確認。

## 準備時程建議

### 評鑑前 3 個月

- [ ] 盤點所有執業醫師、護理師、藥師等醫事人員執照有效期，建立到期追蹤清冊（1.3.1、1.3.2、1.3.3）
- [ ] 確認各病房護病比符合法規，近 3 個月每日紀錄備妥（1.3.2）
- [ ] 確認消防安全設備完成半年定期檢查，安排夜間演練（1.5.2）
- [ ] 啟動醫療品質指標 PDCA 分析，確認異常指標有書面改善計畫（2.2.1）
- [ ] 審查異常事件通報量是否過低，必要時進行部門鼓勵宣導（2.2.3）
- [ ] 確認感染管制委員會年度計畫執行追蹤報告完整（2.4.1）

### 評鑑前 1 個月

- [ ] 執行病歷書寫品質稽核：抽查手術紀錄、出院摘要、知情同意書（1.4.1）
- [ ] 確認資訊安全備份還原測試已執行，離職人員帳號已停用（1.4.2）
- [ ] 清查危險物品暫存區：化學品中文標示、壓縮氣體鋼瓶固定、區域上鎖（1.5.4）
- [ ] 確認廢棄物委外廠商清除許可有效，轉運聯單保存至少 3 年（1.5.7）
- [ ] 核查管制藥品清點記錄逐班完整，雙重上鎖設備符合規定（2.5.6）
- [ ] 確認高警訊藥品清單已張貼於儲藥區，濃縮電解質獨立儲存（2.5.3）
- [ ] 確認手術安全查核（Time Out）執行有書面紀錄（2.6.1）

### 評鑑前 1 週

- [ ] 抽查 3–5 份住院病歷：入院評估 → 照護計畫 → 疼痛記錄 → 出院計畫啟動日期（2.3.1–2.3.10）
- [ ] 確認出院計畫啟動日期在入院後 24–48 小時內，社工轉介案件有完整聯繫紀錄（2.3.10）
- [ ] 實地走查各病房：逃生路線圖更新張貼、病人疏散計畫（含臥床病人）可查閱（1.5.2）
- [ ] 確認申訴資訊已公告於病房護理站與門診大廳（2.1.4）
- [ ] 確認手部衛生稽核數據備妥，PPE 存放位置及安全針具設備配置正確（2.4.2）

### 評鑑當天

- [ ] 依評鑑區塊分類放置文件夾，使用不同顏色區分主要章節
- [ ] 備齊近 3 個月護病比每日紀錄、消防演練紀錄（含照片）
- [ ] 提醒護理人員熟知 SBAR 交班格式及跌倒/壓傷風險評估流程
- [ ] 確認高風險設備（呼吸器、除顫器、電刀）使用前查核表已填寫
- [ ] 備妥品質管理委員會近 12 個月會議記錄及指標趨勢圖

## 優先準備項目

> 以下依必要（★）與重點（⚠️）分類，必要項目未達標將嚴重影響評鑑結果。

### 第一章：院務管理（1.x）

#### 必要項目（★）

| 條文 | 指標名稱 | 準備重點 |
|------|---------|---------|
| 1.3.1 | 醫師人力配置 | 所有執業醫師執照效期有效，執業地點登記正確；外聘醫師文件同樣需完整 |
| 1.3.2 | 護理人力配置 | 各病房近 3 個月每日護病比記錄符合法規，夜班護理人力班表可查 |
| 1.3.3 | 醫事人員配置 | 藥師、放射師、檢驗師、治療師執照有效，執業登記完整 |
| 1.4.1 | 病歷書寫與管理 | 抽查避免 Copy-Paste 問題，手術紀錄、出院摘要簽名完整，電子病歷符合法規 |
| 1.5.2 | 消防安全管理 | 半年定期檢查報告、至少 2 次演練（含 1 次夜間）、病房逃生圖、臥床病人疏散計畫 |

| 條文 | 指標名稱 | 準備重點 |
|------|---------|---------|
| 1.1.3 | 品質管理組織 | 委員會會議紀錄需有實質討論與決議追蹤，備近 12 個月指標趨勢圖 |
| 1.2.3 | 職業安全衛生 | 危害識別紀錄涵蓋主要作業區，近 2 年職安事故通報改善紀錄 |
| 1.3.5 | 新進人員職前訓練 | 每位新進員工有簽名紀錄及測驗成績，涵蓋病人安全、感染管制、消防逃生 |
| 1.3.6 | 在職教育訓練 | 各職類年度訓練計畫及實際完成時數統計，未達時數者有補救紀錄 |
| 1.4.2 | 資訊安全管理 | 備份還原測試紀錄、離職人員帳號停用查核、資安事件通報紀錄 |
| 1.5.3 | 醫療設備管理 | 設備清冊序號一致，高風險設備（呼吸器、電刀）使用前查核表有填寫記錄 |
| 1.5.4 | 危險物品管理 | 化學品中文標示、壓縮氣體鋼瓶固定、緊急應變程序圖張貼於儲存區旁 |
| 1.5.5 | 緊急應變計畫 | 涵蓋火災、地震、停電、大量傷患；演練紀錄含改善追蹤；指揮系統圖公開張貼 |
| 1.5.7 | 廢棄物管理 | 醫療廢棄物與一般廢棄物嚴格分開，委外廠商許可有效，聯單保存 3 年 |

### 第二章：病人安全與照護品質（2.x）

#### 必要項目（★）

| 條文 | 指標名稱 | 準備重點 |
|------|---------|---------|
| 2.1.1 | 病人基本權利保障 | 入院時告知病人權利書有簽收紀錄，拒絕治療有書面處理程序 |
| 2.1.2 | 知情同意作業 | 委員逐份抽查病歷；同意書須載明說明醫師姓名、說明日期、病人或代理人簽字 |
| 2.1.3 | 病人隱私保護 | 執行診察時注重身體隱私，病歷存取管控紀錄完整 |
| 2.2.1 | 醫療品質指標管理 | 指標含臨床、效率及安全面向，有目標值比較及改善計畫追蹤 |
| 2.2.2 | 病人安全文化推動 | 全院安全文化教育訓練記錄、病人安全目標執行成效書面化 |
| 2.2.3 | 異常事件通報與分析 | 高風險事件有 RCA；三類（不良、警示、Near Miss）均有案例紀錄 |
| 2.4.1 | 感染管制委員會 | 委員會會議紀錄完整（含決議追蹤）；感染管制醫師及護理師人力符合規定 |
| 2.4.2 | 標準防護措施 | 手部衛生稽核執行率達標；隔離病人標誌張貼清楚；安全針具設備配置正確 |
| 2.4.3 | 醫療照護相關感染監測 | CLABSI、VAP 等感染率計算方法標準化；異常時有調查報告及改善追蹤 |
| 2.5.2 | 給藥安全 | 「五對」查核（病人、藥品、劑量、途徑、時間）日常落實，有書面紀錄 |
| 2.5.3 | 高警訊藥品管理 | 高警訊藥品清單張貼儲藥區，濃縮電解質（如 KCl）特別標示、獨立儲存，雙重查核簽名完整 |
| 2.5.6 | 管制藥品管理 | 逐班清點紀錄完整，浪費量雙人簽名，雙重上鎖，任何短缺立即通報 |
| 2.6.1 | 手術安全查核 | Time Out 由所有在場人員共同執行，有書面記錄，委員可能訪談手術室人員 |
| 2.6.2 | 麻醉前評估 | 擇期手術麻醉前評估需在術前完成，ASA 分級紀錄清楚，知情同意書由麻醉科醫師取得 |
| 2.6.3 | 麻醉作業管理 | 麻醉機定期保養校正紀錄、困難插管推車內容物及定期查核紀錄 |

#### 重點項目（⚠️）

| 條文 | 指標名稱 | 準備重點 |
|------|---------|---------|
| 2.3.1 | 病人入院評估 | 入院後 24 小時內完成全面評估（含跌倒、壓傷風險），有書面紀錄 |
| 2.3.2 | 個別化照護計畫 | 跨專業團隊擬定，依病人狀況適時更新，病人及家屬意見有紀錄 |
| 2.3.3 | 醫療團隊溝通與交接班 | SBAR 格式統一，跨科別會診有標準化溝通格式 |
| 2.3.6 | 跌倒預防 | 高風險病人有預防措施並告知家屬；發生跌倒有通報、評估及後續處理 |
| 2.3.7 | 壓傷預防 | 翻身或減壓執行情形可查核；院內壓傷有通報及處理紀錄 |
| 2.3.10 | 出院計畫與準備 | 入院後 24–48 小時內啟動；長照轉介案件有社工介入及轉介聯繫紀錄 |
| 2.5.1 | 藥品管理制度 | 儲藥區溫濕度監測紀錄，定期藥品盤點並保留記錄 |
| 1.7.2 | 醫療事故處理 | 每季至少 1–2 件事故 RCA，品質委員會有討論紀錄及後續追蹤 |

## 常見錯誤

1. **執照過期仍在執業**：執業醫師或醫事人員執照未建立系統化到期追蹤，評鑑前才發現過期（1.3.1、1.3.2、1.3.3）
2. **護病比記錄中斷**：未保存每日護病比記錄，僅有月報表，無法呈現夜班覆蓋情形（1.3.2）
3. **病歷大量 Copy-Paste**：電子病歷中複製貼上導致內容不符實況，手術紀錄或出院摘要簽名不完整（1.4.1）
4. **知情同意書說明不完整**：同意書已簽，但未記載說明醫師姓名及說明時間（2.1.2）
5. **異常事件通報量過低**：院內通報文化不足，評鑑反而被視為管理缺失；三類事件（不良、警示、Near Miss）需均有案例（2.2.3）
6. **RCA 流於形式**：醫療事故有通報但無根本原因分析，改善措施無法追蹤（1.7.2）
7. **消防疏散演練缺夜間場次**：全年演練均為白天，未執行夜間演練，且臥床病人疏散計畫未納入（1.5.2）
8. **廢棄物混置**：醫療廢棄物與一般廢棄物未確實分開，或委外廠商清除許可已過期（1.5.7）
9. **高警訊藥品未特別標示**：濃縮電解質未獨立儲存，雙重查核簽名紀錄不完整（2.5.3）
10. **出院計畫啟動過晚**：出院計畫在住院末期才啟動，無法呈現 24–48 小時內啟動的書面紀錄（2.3.10）

### 文件準備

- 依**院務管理**與**病人安全照護**兩大架構分色分類文件夾
- 必要項目（執照、護病比、消防演練、知情同意書、管制藥品清點）各備獨立索引夾，方便委員快速查閱
- 備妥 5 份住院病歷紀錄供抽查（從入院評估 → 照護計畫 → 給藥記錄 → 出院計畫）
- 品質指標近 12 個月趨勢圖印製為視覺化報表，置於品質管理資料夾封面

### 現場注意

- **病房走道暢通**：移除走廊障礙物，確認緊急疏散路線無阻礙
- **各病房逃生圖**：確認已更新並張貼於明顯位置，且含臥床病人疏散方式說明
- **高風險設備就緒**：呼吸器、除顫器、困難插管推車備品完整，使用前查核表已填寫
- **廢棄物暫存區**：實地確認醫療廢棄物與一般廢棄物確實分開，容器標示清楚，區域上鎖

### 訪談準備

- **護理人員**：熟知 SBAR 交班格式、跌倒及壓傷風險評估流程、「五對」給藥查核、手部衛生稽核
- **藥師**：能說明高警訊藥品管理、管制藥品清點流程及給藥安全 SOP
- **感染管制護理師**：能說明標準防護措施、隔離類型及手部衛生推動成效
- **品質管理人員**：能說明品質指標選定依據、異常指標的改善措施、RCA 執行案例
- **院長/主管**：能說明院務發展計畫執行成效、近期品質改善亮點與下年度目標
