# D16. D1 配合政策執行（加分）

> **負責**：機構負責人　**審查**：資料查核、訪談

## 評鑑基準（WHAT）

1. 積極配合衛生主管機關推動政策（如母嬰親善、促進母乳哺育等），有具體執行成效
2. 通過母嬰親善醫療院所認證，或積極推廣純母乳哺育，有認證文件或執行計畫
3. 參與衛生主管機關辦理之品質提升計畫，有參與記錄及成效報告
4. 推行創新服務（如遠距照護諮詢、App 互動衛教等），有具體執行成效
5. 建立電子化照護記錄系統，提升照護效率及資料完整性，有導入成效說明
