# 身心障礙福利機構評鑑準備完整指南

> 109年度身心障礙福利機構評鑑，共 49 項指標，涵蓋行政組織及經營管理（行1–行11）、環境設施及安全維護（環12–環31）、專業服務（專32–專49）三大面向。

## 準備時程建議

### 評鑑前 3 個月

- [ ] 計算近3年度平均業務支出占支出合計是否達 75%（行9）——未達者需盡快調整財務配置
- [ ] 盤點社工、護理、教保/訓練員、生活服務員四類人力比，以106–108年歷月平均值計算（行6）
- [ ] 確認服務對象實際人數達核定人數 80% 以上（扣除緊急安置床位）（行3）
- [ ] 更新「全國身心障礙福利資訊整合平台–身心障礙福利機構管理系統」資料（行3）
- [ ] 核查員工良民證或性侵害犯罪查閱記錄是否完整建檔（行3）
- [ ] 確認當年度工作計畫及預算已提董事會核准並函報主管機關（行1）
- [ ] 啟動 ISP 個別化服務計畫年度更新作業，確認每位服務對象均已召開計畫會議（專32）

### 評鑑前 1 個月

- [ ] 確認新進員工3個月內已完成24小時職前訓練（行5）
- [ ] 確認直接服務人員每人達20小時在職訓練（含4小時應急管制＋2小時口腔照護）（行5）
- [ ] 核對急救訓練內部參加率達 80%，性侵害防治專業訓練已辦理（行5）
- [ ] 確認廚工及夜間人員年度健康檢查（含A肝、傷寒、糞便檢查）已完成（行4）
- [ ] 確認消防安全設備半年檢修申報已完成，並備有3年完整紀錄（環16）
- [ ] 確認緊急災害應變演練每年至少2次（含夜間演練1次）已執行，並有完整腳本與檢討記錄（環17）
- [ ] 抽查3–5份服務對象的完整紀錄（ISP會議→計畫→執行→半年檢討）（專32–專34）
- [ ] 確認個案研討每年至少2次、督導紀錄每月至少1次（含至少1次外部專家督導）（專35）

### 評鑑前 1 週

- [ ] 現場巡查緊急呼叫設備功能是否正常（無障礙廁所、浴室、寢室每床）（環14）
- [ ] 確認逃生路徑雙向暢通，防火門可隨時關閉（環15）
- [ ] 確認用電設備本月已完成自主檢查，防火管理人證書在效期內（環16）
- [ ] 確認浴廁比例不低於1:6，隱密性符合規定（男女分廁、隔間或門簾）（環12）
- [ ] 確認藥物儲存上鎖、標示完整（姓名、服用時間）（專45）
- [ ] 核查食物留樣：每餐留樣獨立盛裝冷藏48小時（專44）
- [ ] 確認體溫健康監視紀錄（服務對象及工作人員）每日完整（專47）
- [ ] 確認社區資源清冊已更新，每位服務對象每月至少1次外出社區活動紀錄（專48）

### 評鑑當天

- [ ] 依三大面向分類擺放文件夾，個案完整紀錄備5份以上供抽查
- [ ] 確認財務報表（資產負債表、收支餘絀表、現金流量表等）已備妥，函報主管機關副本齊全（行9）
- [ ] 確認公安申報報告書及核發合格證明現場置有（環16）
- [ ] 提醒生活服務員展現促進服務對象自主的照護態度（專38）
- [ ] 提醒社工能說明ISP會議流程及家屬（監護人）參與機制（專32）

## 優先準備項目

以下指標標記為 ⚠️，代表最容易被扣分或影響評鑑等第的項目：

### 行政組織及經營管理（行）

| 指標 | 警告重點 |
|------|---------|
| ⚠️ 行2 機構管理制度 | 工作手冊需涵蓋組織架構、業務執掌、入出機構辦法等，入出機構管理辦法須涵蓋 **5 項以上內容** |
| ⚠️ 行3 機構配合情形 | 實際服務人數需達核定人數 **80%**；平台資料需定期更新；員工性侵害犯罪查閱記錄不可漏人 |
| ⚠️ 行5 員工訓練 | 新進人員3個月內24小時；直接服務每人20小時（含應急4h＋口腔2h）；急救訓練參加率需達 **80%** |
| ⚠️ 行6 專業服務人力 | 8分最高分項，四類人力比以歷月平均值計算，夜間人力不符酌扣0.5分 |
| ⚠️ 行9 財務報告 | **業務支出佔支出合計3年平均需≧75%**，公立機構或財務支出比例偏低者須提前確認 |

### 環境設施及安全維護（環）

| 指標 | 警告重點 |
|------|---------|
| ⚠️ 環12 浴廁 | 浴廁比不得小於1:6，重度失能機構每60人需1套臥床專用洗澡設備 |
| ⚠️ 環14 緊急呼叫設備 | 無障礙廁所、浴室、寢室（重度失能每床）均需設置，且功能正常 |
| ⚠️ 環15 逃生路徑 | 雙向逃生出口；防火門需隨時關閉或與火警連動；等待救援空間需具防火區劃功能 |
| ⚠️ 環16 公消防安全 | **核心指標影響評鑑等第**：公安申報、消防半年檢修3年完整紀錄、防火管理人有效證書、每月用電自主檢查 |
| ⚠️ 環17 緊急災害演練 | 每年至少2次（含夜間1次），演練需有腳本、過程紀錄、檢討會議及修正方案 |

### 專業服務（專）

| 指標 | 警告重點 |
|------|---------|
| ⚠️ 專32 ISP 個別化服務計畫 | 每位服務對象每年召開計畫會議，新進者2個月內完成（生活重建1個月）；**不可套制式模板** |
| ⚠️ 專33 服務目標 | 短期目標須「可觀察、可評量且具功能性」，需根據評估結果擬定，不可脫離評估資料 |
| ⚠️ 專35 專業團隊運作 | 個案研討每年至少2次、督導每月至少1次、每年至少1次外部專家督導 |
| ⚠️ 專38 體能及休閒活動 | 每週至少2小時體能活動；重度失能機構另需評估每日下床、被動肢體活動及感官刺激 |
| ⚠️ 專44 膳食服務 | 菜色15天不重複、菜單需營養師簽名、食物留樣獨立盛裝冷藏48小時 |
| ⚠️ 專45 用藥安全 | 藥物儲存需上鎖，標示需含姓名及服用時間，現場實查重點 |
| ⚠️ 專47 傳染病防治 | 每日監視體溫健康紀錄（服務對象＋工作人員），落實手部衛生稽核 |

## 常見錯誤

1. **財務比例未達標**：業務支出未達支出合計75%，年度結束才發現，已來不及調整（行9）
2. **人力比計算方式錯誤**：以單月快照計算，而非106–108年歷月平均值；夜間人力未納入計算（行6）
3. **ISP 套模板**：所有服務對象使用相同制式計畫，未反映個別評估結果及家屬意見（專32）
4. **服務目標不具可評量性**：目標寫「改善溝通能力」等模糊敘述，無法觀察或測量（專33）
5. **訓練時數達標但無效益評量**：訓練簽到表齊全，但欠缺效益評量紀錄（行5）
6. **緊急呼叫設備功能失常**：設備裝設但未定期測試，評鑑現場測試時無法正常發報（環14）
7. **演練記錄不完整**：有做演練但無腳本、無照片、無檢討會議紀錄（環17）
8. **平台資料未更新**：全國身心障礙福利資訊整合平台長期未更新，與實際服務狀況不符（行3）
9. **藥物標示不全**：藥物盒未標示服務對象姓名或服用時間（專45）
10. **社區活動參與無法追蹤**：無個別參與紀錄，無法自主出席者亦未造冊說明原因（專48）

## 評鑑當天注意

### 文件準備

- 依**三大面向**（行政管理、環境設施、專業服務）分類擺放文件夾，用不同顏色標示
- ISP 完整紀錄（計畫→執行→半年檢討）準備 5 份備用，依服務對象分冊
- 財務報表、公安申報報告書、消防檢修紀錄單獨一冊，評委進門即可取用
- 訓練記錄、會議紀錄依時間序排列

### 現場注意

- **逃生路徑淨空**：安全梯出入口及防火區劃門周圍 1.5 公尺地面無堆放物
- **緊急呼叫設備**：評鑑前實際按壓測試，確認工作站或走廊顯示正常
- **藥物儲存**：確認儲藥櫃上鎖，每盒標示姓名及服用時間
- **浴廁隱密性**：廁所有隔間或門簾、男女分廁，浴室有隔間或門簾

### 訪談準備

- **社工**：能說明 ISP 擬訂流程、家屬（監護人）參與方式、個案研討機制
- **護理**：能說明用藥管理 SOP、傳染病防治措施、緊急事件處理流程
- **教保員/訓練員**：能說明體能活動及休閒活動內容如何配合服務對象個別需求
- **機構主任/負責人**：能說明業務支出財務比例計算、財物管理制度、年度工作計畫執行情形
- **生活服務員**：需了解所負責服務對象的ISP重點及緊急呼叫設備使用方式

### 財務管理特別注意

- ⚠️ **業務支出≥75%** 是本機構類型特有的財務指標，評委通常會索取3年財務報表進行計算，務必提前備妥計算明細
- 支出在新臺幣1萬元以上應全數以支票或金融機構撥付，現金支出憑據若有疑義將被扣分
- 指定用途捐款之專戶存款需足額儲存，公開徵信截圖需備妥（行11）
