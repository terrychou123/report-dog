# 寫作風格指南（Style Guide）

## 語言

- 全文使用**繁體中文**
- 專業術語維持原文（如「評鑑基準」、「服務對象」、「照顧計畫」）
- 機構名稱使用官方全稱（如「日間照顧中心」，不用「日照中心」作為標題）
- 法規引用保留原始條文用語

## 語氣與風格

- **實用導向**：重點是「怎麼做」，不是「是什麼」
- **精簡直接**：每條建議一句話，不重複說明
- **警告明確**：⚠️ 標記容易被扣分、常見錯誤的項目
- **提示友善**：📌 標記連結到相關資源

## 指標引用格式

- 短碼 + 數字：`權1`、`專5`、`管12`
- 完整引用：`[權1 服務資訊公開](../items/01-service-info.md)`

## 條列格式

```markdown
<!-- 評鑑基準：使用有序清單，保留原文 -->
1. 製作機構簡介或文宣，且內容完整
2. 隨時更新簡介或文宣與活動訊息

<!-- 準備建議：使用無序清單，務實建議 -->
- 公告需在機構顯眼處，委員現場會確認
- 網站資訊需與實際服務內容一致，包含費用、服務項目

<!-- 警告：用 blockquote + ⚠️ -->
> ⚠️ **常見缺失**：網站資料未更新，顯示舊年度費用標準
```

## 表格格式

跨機構對照表：

```markdown
| 機構類型 | 指標 | 具體基準 |
|---------|------|---------|
| 日間照顧中心 | 權4 | 個案資料電腦化者有權限設定 |
| 住宿型機構 | 管X | 個人資料依法保存 |
```

## 標題層級

```
# 頁面標題（frontmatter title，Markdown 中不重複）
## 一級章節（WHAT、HOW、常見缺失等）
### 二級章節（如區塊名稱、子主題）
#### 以上不使用
```

## 禁止事項

- 不得編造未出現在原始資料（sources/）中的評鑑標準
- 不得臆測評分結果（如「這題一定得滿分」）
- 不得使用舊年度已廢止的規定（需標記年度）
- 不得引用非官方來源的評分細則
